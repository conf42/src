# Transforming Knowledge Systems with Embedded Analytics in Cloud-Native Architectures

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Harshita Dubey](https://www.conf42.com/speaker_Harshita_Dubey) (Senior Technical Program Manager @ Apex Fintech Solutions). Page: https://www.conf42.com/Kube_Native_2025_Harshita_Dubey_knowledge_analytics_architectures

Video: https://www.youtube.com/watch?v=N0it3_YmwWI

## Abstract

Discover how a global enterprise used Kubernetes-native microservices and embedded analytics to transform a legacy KMS into a dynamic, self-optimizing knowledge ecosystem cutting retrieval time by 33% and saving $3.7M annually. Learn the blueprint to do it yourself.
