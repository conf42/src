# The 2025 State of JavaScript Testing

A talk at [Conf42 Remix 2026](https://www.conf42.com/remix2026) by [Daniel Afonso](https://www.conf42.com/speaker_Daniel_Afonso) (Senior Developer Advocate @ PagerDuty). Page: https://www.conf42.com/Remix_2026_Daniel_Afonso_state_testing_tech

Video: https://www.youtube.com/watch?v=CRzEAv1GzSI

## Abstract

This talk will go over what changed it the past decade regarding testing Web applications. We will focus on practices, patterns, and library changes and learn what the future holds for us around test runners, testing libraries, mocking, production practices, and AI-based tools.
