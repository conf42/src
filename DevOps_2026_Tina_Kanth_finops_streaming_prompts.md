# Real-Time FinOps Intelligence: Template-Driven Prompt Engineering for Streaming Financial Events

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Tina Kanth](https://www.conf42.com/speaker_Tina_Kanth) (Software Engineer @ Microsoft). Page: https://www.conf42.com/DevOps_2026_Tina_Kanth_finops_streaming_prompts

Video: https://www.youtube.com/watch?v=QNxfOaMrl54

## Abstract

Turn millions of financial events/sec into instant, auditable ops decisions. Learn battle-tested prompt templates that fuse streams + observability into structured outputs for triage, anomaly detection, and schema-drift recovery, boosting accuracy 10–15 points and accelerating DevOps automation.
