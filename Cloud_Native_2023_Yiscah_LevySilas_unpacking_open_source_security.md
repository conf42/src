# Unpacking Open Source Security in Public Repos & Registries

A talk at [Conf42 Cloud Native 2023](https://www.conf42.com/cloud2023) by [Yiscah Levy-Silas](https://www.conf42.com/speaker_Yiscah_LevySilas) (Software Engineer @ ARMO). Page: https://www.conf42.com/Cloud_Native_2023_Yiscah_LevySilas_unpacking_open_source_security

Video: https://www.youtube.com/watch?v=yiE0K3ZUmmk

## Abstract

The container ecosystem has exploded in the decade since it's been introduced and today boasts many public facing resources - open source projects & public registries. This talk we will unveil first of its kind research conducted by scanning the most popular and widely adopted open source projects.

## Key takeaways

- Armo is a Kubernetes security company. Kubescape is a security posture platform which shows you misconfigurations inside your cluster and guides you on how you can improve your security. Today we're going to compare two samples, one against the other. The first is the general population and the second is the sample of CNCF graduated projects.

- We saw in nearly 37,000 images that we scanned to high severity vulnerability. Then we have libgCrypt, which was in nearly 15,000 and high as well after that. To make sense of this data, we went over each one of these vulnerabilities manually. Are they really exploitable and how relevant are they?

- In the graduated projects and in general the CNCF projects have much less vulnerabilities. One of the reasons is because we're using newer technologies. A vulnerability that an image scanner has returned is not always an exploitable security issue.

- Kubescape uses controls which are tests of different properties of kubernetes objects. A lot of workloads don't use immutable file systems, which kind of makes sense. But a lot are not configuring memory limits, resource limits, common label usage.

- CNCF graduate projects are only slightly better in terms of vulnerabilities. In general, there's a lot of work to be done to make vulnerability scanners more effective and more relevant.
