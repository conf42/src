# Architecting Scalable Order Management Systems with Microservices

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Jubin Thomas](https://www.conf42.com/speaker_Jubin_Thomas) (Technical Architect @ Signet Jewelers). Page: https://www.conf42.com/Kube_Native_2024_Jubin_Thomas_order_management_scalable_microservices

Video: https://www.youtube.com/watch?v=95QJjT1EEfE

## Abstract

Learn innovative techniques for building scalable order management systems with microservices. Gain insights into decomposition, integration, scalability, resilience, and deployment using Kubernetes.
Unlock the power of microservices in order management.
