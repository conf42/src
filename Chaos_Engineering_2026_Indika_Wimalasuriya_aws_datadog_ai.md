# Breaking the Brain: Chaos Engineering for AI-Native Apps on AWS with Datadog

A talk at [Conf42 Chaos Engineering 2026](https://www.conf42.com/chaos2026) by [Indika Wimalasuriya](https://www.conf42.com/speaker_Indika_Wimalasuriya) (Director of SRE & Observability @ Virtusa). Page: https://www.conf42.com/Chaos_Engineering_2026_Indika_Wimalasuriya_aws_datadog_ai

## Abstract

Abstract  AI-native applications fail differently from traditional services. A Bedrock throttle, a slow tool call, a stale vector index or an agent stuck in a retry loop rarely produces a clean 500. More often you get a confident wrong answer, a quietly tripled token bill or a workflow that never finishes. Classic chaos experiments (kill an instance, add latency) are necessary but no longer sufficient.  This presentation focus how to run chaos engineering on AI-native workloads hosted on AWS and observed with Datadog. We start with a failure-mode taxonomy for LLM apps and agents:  model throttling and regional unavailability latency and timeout cascades tool and MCP failures RAG and vector-store degradation context or prompt poisoning runaway token and cost loops  Then we turn each one into a testable hypothesis. You’ll see how to inject faults using AWS Fault Injection Service plus an application-level fault layer. You’ll also see how to use Datadog LLM Observability, APM traces, monitors and SLOs to confirm the system degrades the way you expected. We finish with a demo of an agentic application on AWS taking a controlled failure, and how guardrails, fallbacks and circuit breakers held up (or didn’t).  You’ll leave with a repeatable experiment template and a starter set of Datadog signals for the resilience of any AI-native system.  Key takeaways  - A failure-mode catalogue for LLM apps and agents, beyond “the API returned an error” - How to define steady state and hypotheses for non-deterministic systems, using quality, cost and latency SLOs - A practical approach combining AWS FIS and app-level fault injection to test models, tools and retrieval - Which Datadog signals confirm a failure was contained: traces, LLM spans, token and cost metrics, and monitors tied to SLOs - How to run game days for AI teams safely, with blast-radius limits and rollback
