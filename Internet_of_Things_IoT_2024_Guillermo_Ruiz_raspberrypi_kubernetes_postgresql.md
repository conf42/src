# Building the Largest Raspberry Pi Kubernetes PostgreSQL Cluster

A talk at [Conf42 Internet of Things (IoT) 2024](https://www.conf42.com/iot2024) by [Guillermo Ruiz](https://www.conf42.com/speaker_Guillermo_Ruiz) (Senior Developer Advocate @ AWS). Page: https://www.conf42.com/Internet_of_Things_IoT_2024_Guillermo_Ruiz_raspberrypi_kubernetes_postgresql

## Abstract

Unleashing the power of 63 Raspberry Pis in a Kubernetes-managed PostgreSQL cluster, with real-time observability in the cloud. Explore how we optimize IoT infrastructure for peak performance and scalability.
