# Fault isolation using shuffle sharding

A talk at [Conf42 Site Reliability Engineering 2021](https://www.conf42.com/sre2021) by [Andrew Robinson](https://www.conf42.com/speaker_Andrew_Robinson) (Principal Solution Architect @ AWS). ## Abstract

Distributing user requests to resources in a combinatorial way to reduce the impact of failures and providing logical isolation.
