# Unifying Online and Offline Worlds: A Machine-Learning Framework for Cross-Channel Attribution and Marketing ROI

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Ashutosh Verma](https://www.conf42.com/speaker_Ashutosh_Verma) (Gunukula ravikumar @ Meta). Page: https://www.conf42.com/Machine_Learning_2026_Ashutosh_Verma_scalability_architecture_distributed

Video: https://www.youtube.com/watch?v=hmm03ACR8EE

## Abstract

Discover how machine learning can finally connect digital and physical customer journeys. Learn a practical, scalable framework for cross-channel attribution that boosts ROI, improves decisions, and reveals insights no single channel can show.
