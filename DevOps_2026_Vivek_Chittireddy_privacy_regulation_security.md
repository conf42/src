# Privacy by Design for DevOps: Building Scalable, Secure, Regulation-Ready Data Systems

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Vivek Chittireddy](https://www.conf42.com/speaker_Vivek_Chittireddy) (Data Engineer @ Meta). Page: https://www.conf42.com/DevOps_2026_Vivek_Chittireddy_privacy_regulation_security

Video: https://www.youtube.com/watch?v=D4G8BW60edk

## Abstract

Learn how to embed Privacy by Design into DevOps pipelines using real-world techniques differential privacy, anonymization, homomorphic encryption to build scalable, secure, regulation-ready data systems without slowing innovation.
