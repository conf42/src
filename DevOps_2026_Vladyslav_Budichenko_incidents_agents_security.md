# AI Agents for Incident Response: The Good, the Bad, and the Ugly

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Vladyslav Budichenko](https://www.conf42.com/speaker_Vladyslav_Budichenko) (Senior Software Engineer @ Vocaly AI). Page: https://www.conf42.com/DevOps_2026_Vladyslav_Budichenko_incidents_agents_security

Video: https://www.youtube.com/watch?v=xMiKK123-Ac

## Abstract

AI agents are joining your on-call team - but can you trust them? This talk exposes where they supercharge incident response, where they cause chaos, and how to use them safely with tools like MCP. Real lessons, no AI hype.
