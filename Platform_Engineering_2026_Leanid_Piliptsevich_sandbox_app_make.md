# Make your app its own sandbox

A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Leanid Piliptsevich](https://www.conf42.com/speaker_Leanid_Piliptsevich) (Java developer @ EPAM). Page: https://www.conf42.com/Platform_Engineering_2026_Leanid_Piliptsevich_sandbox_app_make

Video: https://www.youtube.com/watch?v=Qi7BeKM3NRw

## Abstract

Can an application become its own sandbox? A document parser should not automatically inherit the same operating-system permissions as an HTTP client. Yet components within a JVM application commonly share the privileges of the entire process. This talk introduces MazeWall, an experimental open-source toolkit that lets Java and Kotlin applications define their own restrictions, enforced by the Linux kernel. Combining seccomp, Landlock, and the JDK Foreign Function & Memory API, MazeWall applies different syscall and filesystem policies to selected workloads. Practical examples will show how runtime profiling helps generate policy candidates, how kernel-enforced restrictions can limit the impact of malicious inputs, and when separate worker processes are needed for stronger isolation. The presentation examines how application-aware sandboxing complements containers, its performance and deployment trade-offs, and its security limitations. Attendees will learn how to give application components fewer privileges—and why restricting a thread is not the same as isolating arbitrary hostile code.
