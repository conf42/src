# Infrastructure as Code for Enterprise Networks: Automating SD-WAN and Zero Trust

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Imran Abdul](https://www.conf42.com/speaker_Imran_Abdul) (Network Operations Manager @ Pace University, New York). Page: https://www.conf42.com/DevOps_2026_Imran_Abdul_sdwan_networking_automation

Video: https://www.youtube.com/watch?v=OKWke4Hmt74

## Abstract

Stop treating networks like snowflakes! Learn how to apply GitOps and IaC to enterprise networking with SD-WAN automation, zero trust segmentation, and CI/CD pipelines for network changes. Real-world patterns for DevOps teams ready to automate their network infrastructure.
