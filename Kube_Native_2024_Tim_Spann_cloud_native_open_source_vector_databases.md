# Unleashing the Potential of Cloud Native Open Source Vector Databases

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Tim Spann](https://www.conf42.com/speaker_Tim_Spann) (Principal Developer Advocate @ Zilliz). Page: https://www.conf42.com/Kube_Native_2024_Tim_Spann_cloud_native_open_source_vector_databases

Video: https://www.youtube.com/watch?v=X5fR2SIS8x8

## Abstract

The quick and easy way to run a true cloud native open source vector database for RAG, Semantic Search, Image Search and many more use cases the cloud native way.
