# A New Way to Build for the Web

A talk at [Conf42 Rustlang 2024](https://www.conf42.com/rustlang2024) by [Andreas Moller](https://www.conf42.com/speaker_Andreas_Moller) (Co-founder @ toddle). Page: https://www.conf42.com/Rustlang_2024_Andreas_Moller_web_build_design_development

Video: https://www.youtube.com/watch?v=7bnzpUfZF6A

## Abstract

Is a text editor really the best tool to build visual web apps? 

- What if developers no longer had to replicate designs from a Figma file only to be told it's incorrect?
- What if designers could change the border-radius on a button without needing a developer?
