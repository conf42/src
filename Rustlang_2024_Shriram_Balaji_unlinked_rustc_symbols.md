# Rust Unlinked - A Journey Through Rustc, Symbols, and Static Libraries

A talk at [Conf42 Rustlang 2024](https://www.conf42.com/rustlang2024) by [Shriram Balaji](https://www.conf42.com/speaker_Shriram_Balaji) (Engineering @ Microsoft). Page: https://www.conf42.com/Rustlang_2024_Shriram_Balaji_unlinked_rustc_symbols

Video: https://www.youtube.com/watch?v=2xs6eGgGvog

## Abstract

Curious how a linker works with Rust programs on Unix-like systems? I’ll share my insights on linking, rustc, symbol resolution, and the ELF format. We’ll explore the quirks of manually linking static libraries, understand LTO, compare linkers, and peek into .o files. Let’s link all the pieces together!
