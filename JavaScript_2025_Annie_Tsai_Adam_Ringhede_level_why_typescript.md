# Level Up: Why TypeScript/JavaScript for game development?

A talk at [Conf42 JavaScript 2025](https://www.conf42.com/js2025) by [Annie Tsai](https://www.conf42.com/speaker_Annie_Tsai) (Co-Founder @ Hology) and [Adam Ringhede](https://www.conf42.com/speaker_Adam_Ringhede) (Co-founder @ Hology). Page: https://www.conf42.com/JavaScript_2025_Annie_Tsai_Adam_Ringhede_level_why_typescript

Video: https://www.youtube.com/watch?v=coA-a5c5-hI

## Abstract

Discover how TypeScript and JavaScript empower web developers to create modern games, and why now is the best time! Learn about tools, workflows, and real-world examples that make these languages ideal for building cross-platform interactive experiences on the web and mobile apps!
