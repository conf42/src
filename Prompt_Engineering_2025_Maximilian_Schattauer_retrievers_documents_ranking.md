# Beyond semantic retrievers: leveraging LLMs for question-based document ranking

A talk at [Conf42 Prompt Engineering 2025](https://www.conf42.com/prompt2025) by [Maximilian Schattauer](https://www.conf42.com/speaker_Maximilian_Schattauer) (Technical Consultant | Data & AI @ Perelyn GmbH). Page: https://www.conf42.com/Prompt_Engineering_2025_Maximilian_Schattauer_retrievers_documents_ranking

Video: https://www.youtube.com/watch?v=KqEQGHFoxXI

## Abstract

We improved complex document retrieval by using an LLM-driven pairwise ranking approach, prompting the model to judge which document better answers a question. This method outperformed traditional retrievers, boosting recall@k in sspecial retrieval scenarios.
