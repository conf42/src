    Abstract

    Relying on third-party data vendors for critical real-time features often leads to latency spikes, missing events, and lost revenue. When external feeds delayed esports draft updates by minutes, we built our own internal telemetry streaming platform from the ground up. In this talk, I will share how BetBoom designed an in-house real-time platform using Dota 2 Game State Integration (GSI), Go, WebSockets, and gRPC to process low-level game snapshots and stream live pick/ban events directly to millions of users. I will talk about: 1. How to turn unordered, repeating HTTP snapshots into a deterministic sequence of stateful business events. 2. Implementing JWT-authenticated telemetry intake, PostgreSQL transactional state management, and real-time WebSocket broadcasting. 3. Designing an internal platform compatible with legacy third-party contracts, enabling seamless automated fallback. 4. Business Impact: How moving to an in-house telemetry platform scaled to 5M+ views and quadrupled user conversion from 8.4% to 31.2%.
