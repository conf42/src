# Cloud-Native Defense-in-Depth Security for Mission-Critical Services in Managed Kubernetes

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Karthikeyan Thirumalaisamy](https://www.conf42.com/speaker_Karthikeyan_Thirumalaisamy) (Principal Software Engineer @ Microsoft). Page: https://www.conf42.com/Kube_Native_2025_Karthikeyan_Thirumalaisamy_security_missioncritical_kubernetes

Video: https://www.youtube.com/watch?v=X1mOrm9x-6Y

## Abstract

Kubernetes powers today’s most critical services - but are they truly secure? This talk unveils a cloud-native defense-in-depth blueprint for AKS, EKS, and GKE, showing how to block insider threats, supply chain attacks, and runtime exploits while keeping innovation fast.
