# DevSecOps beyond GitHub Advanced Security

A talk at [Conf42 DevSecOps 2026](https://www.conf42.com/devsecops2026) by [Peter De Tender](https://www.conf42.com/speaker_Peter_De_Tender) (Senior Content Developer @ Microsoft). Page: https://www.conf42.com/DevSecOps_2026_Peter_De_Tender_github_codescanning_sast

Video: https://www.youtube.com/watch?v=z772CLcVUqM

## Abstract

DevSecOps tries to make DevOps teams aware about integrating security into each and every step of the process. But this is complex, with a need to integrate a whole set of tools. But no more, thanks to GitHub Advanced Security, baked into your trusted DevOps environment. In this session, Peter will guide you through a full range of built-in GitHub security features, beyond the GHAS - GitHub Advanced Security plan you (might) already pay for.
