# Green Evals, Broken Agents: Making Evals a First-Class Deployment Artifact

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Dylan Ler](https://www.conf42.com/speaker_Dylan_Ler) (Forward Deployed Engineer (FDE Team) @ Adobe). Page: https://www.conf42.com/MLOps_2026_Dylan_Ler_evals_agents_deployment

## Abstract

An agent's eval suite can be green while the agent is broken. Dylan Ler has run evals and deployment as a practitioner and kept hitting the same failures in his own published experiments. In his Latent Pager Memory study, reporting only F1 and latency made the method look like a clean win (+41.5% F1, 2.55x faster); adding hallucination (0.292 to 0.580) turned that win into a design problem. Selecting checkpoints by validation loss instead of the metric that mattered would have cost about 35% F1. A one-line generation fix moved test F1 more than any architecture change. In his calibration audit, accuracy and Brier score ranked models in opposite orders. In 'Worlds That Teach Back', 85.6% token accuracy said nothing about whether generated physics conserved energy.  The talk turns those lessons into a pipeline: datasets, graders, and thresholds versioned and owned; deterministic checks alongside calibrated LLM judges; evals that score trajectories, invariants, and tool calls, not only final answers; a sentinel suite on every prompt, tool, or model change; and every observed failure turned into a minimal regression test with a measured reproduction rate. Attendees leave with a CI blueprint and a budget for what to run per PR, nightly, and pre-release.
