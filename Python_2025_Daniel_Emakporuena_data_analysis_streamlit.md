## Abstract

Data analysis doesn’t have to be hard, even for beginners. While tools like Power BI and Tableau have limitations, I’ve created an analytical tool using Python, hosted on Streamlit. It allows you to build dashboards and perform EDA easily—no account required. Let me show you!
