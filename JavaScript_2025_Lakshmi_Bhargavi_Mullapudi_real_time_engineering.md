# Real-Time Data Systems: Engineering for Speed, Scale, and Resilience

A talk at [Conf42 JavaScript 2025](https://www.conf42.com/js2025) by [Lakshmi Bhargavi Mullapudi](https://www.conf42.com/speaker_Lakshmi_Bhargavi_Mullapudi) (Software Engineer @ Techstar Group). Page: https://www.conf42.com/JavaScript_2025_Lakshmi_Bhargavi_Mullapudi_real_time_engineering

Video: https://www.youtube.com/watch?v=OlwF7CUHmSs

## Abstract

Learn how real-time data powers fraud detection, personalization, and instant insights! This talk dives into the tools, architectures, and battle-tested strategies behind high-speed, scalable systems. If you care about performance, this is where speed meets engineering mastery.
