# Prompt Engineering for Test Automation: Enhancing AI-Driven Quality Assurance

A talk at [Conf42 Prompt Engineering 2024](https://www.conf42.com/prompt2024) by [Ludovico Besana](https://www.conf42.com/speaker_Ludovico_Besana) (Senior Test Engineer @ Nearform). Page: https://www.conf42.com/Prompt_Engineering_2024_Ludovico_Besana_promptengineering_automation_quality

## Abstract

Discover how prompt engineering can revolutionize test automation by improving the accuracy, speed, and reliability of AI-driven quality assurance in modern software development pipelines.
