# Function vs. Friction: Designing the Right Observability Stack in AWS Cloud

A talk at [Conf42 Observability 2025](https://www.conf42.com/obs2025) by [Prudhvi Raj Atluri](https://www.conf42.com/speaker_Prudhvi_Raj_Atluri) (Associate Architect - Data @ Quantiphi). Page: https://www.conf42.com/Observability_2025_Prudhvi_Raj_Atluri_stack_observability_aws

Video: https://www.youtube.com/watch?v=DlRaIo86zq8

## Abstract

Great observability doesn’t shout—it quietly enables clarity. This talk explores how to evaluate, select, and integrate AWS observability tools so your stack disappears into the background and data-driven decisions take the lead.
