    Abstract

    DevSecOps teams are responsible for Infrastructure as Code, CI/CD security, Kubernetes governance, vulnerability management, observability, compliance, reliability, and incident response. Yet many organizations still depend on engineers to manually review alerts, validate configurations, investigate deployment failures, inspect security findings, and execute operational runbooks. This session explores how AI agents powered by Large Language Models can act as intelligent orchestration layers across the DevSecOps lifecycle. Using the Model Context Protocol, agents can securely interact with Terraform, Kubernetes, GitHub, GitOps pipelines, AWS, Azure, OCI, Splunk, Grafana, CloudWatch, PagerDuty, ServiceNow, security scanners, internal documentation, and approved runbooks. The presentation demonstrates how AI agents can generate and validate Infrastructure as Code, enforce security policies, review pull requests, identify configuration drift, analyze vulnerabilities, verify deployments, correlate telemetry, and assist with incident investigation. A reusable investigation workflow follows a structured 16-step process that includes retrieving incident context, analyzing logs and metrics, reviewing recent code and infrastructure changes, identifying probable root causes, recommending remediation, and escalating high-risk decisions for human approval. The session also examines essential guardrails, including least-privilege access, policy-as-code, approval gates, audit trails, restricted tool permissions, and human-in-the-loop controls. These safeguards help ensure that AI-assisted automation remains secure, explainable, and compliant. Attendees will learn how AI agents can reduce DevSecOps toil, accelerate secure delivery, improve policy enforcement, strengthen incident response, and enable engineering teams to focus on resilience, architecture, and continuous security improvement.
