# You Cannot Fix a Prompt You Cannot See Fail: Debugging the Plan, Not Just the Answer

A talk at [Conf42 Prompt Engineering 2026](https://www.conf42.com/prompt2026) by [Krishna Chaitanya Balusu](https://www.conf42.com/speaker_Krishna_Chaitanya_Balusu) (Senior Software Engineer @ Meta). Page: https://www.conf42.com/Prompt_Engineering_2026_Krishna_Chaitanya_Balusu_debugging_plan_fail

Video: https://www.youtube.com/watch?v=9oRkB-3XWNc

## Abstract

Prompt engineering for single turn prompts has a tight feedback loop: change the prompt, read the output, judge it. Multi step and agentic prompting breaks that loop. When a reasoning chain goes wrong you see a bad final answer, but not which step chose the wrong path. You are tuning a plan you cannot see.  I authored the plan operation for agent planning spans in the OpenTelemetry GenAI semantic conventions (open-telemetry/semantic-conventions-genai#97), accepted upstream in May 2026. It makes the reasoning step a first class, portable span, so you can watch a prompting strategy plan, not just its final output. This talk shows how to instrument the planning step, how to tell a planning failure apart from a tool failure, and how to turn that signal into a measurement loop for prompt iteration. I will walk a demo, built for this talk, that catches a planning fault a final answer check would miss.
