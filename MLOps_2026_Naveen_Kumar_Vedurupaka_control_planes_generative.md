# Shared Control Planes for Generative AI and ML Platforms

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Naveen Kumar Vedurupaka](https://www.conf42.com/speaker_Naveen_Kumar_Vedurupaka) (Independent Researcher @ stealth). Page: https://www.conf42.com/MLOps_2026_Naveen_Kumar_Vedurupaka_control_planes_generative

## Abstract

As Generative AI adoption grows, many enterprises add separate AI infrastructure beside existing machine learning platforms, creating duplicated governance, observability, lineage, model registries, deployment pipelines, and operating processes. This session presents a practical MLOps integration pattern for extending existing ML platforms to support both predictive AI and Generative AI through a shared control plane while keeping workload-specific runtime optimization.  Attendees will learn how classical ML and Generative AI workloads can run across online, near-real-time, and batch serving environments without a full platform redesign. The session explains how common capabilities such as model registry, lineage, observability, identity, governance, rollout strategies, and cost attribution can be reused across both workload types, while runtime extensions support LLM serving, Retrieval-Augmented Generation, parameter-efficient fine-tuning, token streaming, continuous batching, multi-node inference, and unified evaluation workflows.  The session also covers Kubernetes-based reference architecture patterns, deployment contracts, promotion gates, policy enforcement, security controls, operational governance, and cost management practices that help teams absorb Generative AI into existing ML ecosystems with less duplication. Attendees will leave with practical guidance for balancing scalability, safety, observability, performance, and operational efficiency while modernizing enterprise AI platforms under a unified MLOps foundation.
