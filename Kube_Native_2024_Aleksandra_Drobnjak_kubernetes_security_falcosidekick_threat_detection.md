# Runtime Kubernetes Security: Hands-On Threat Detection with Falcosidekick

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Aleksandra Drobnjak](https://www.conf42.com/speaker_Aleksandra_Drobnjak) (Customer Solutions Engineer @ Sysdig). Page: https://www.conf42.com/Kube_Native_2024_Aleksandra_Drobnjak_kubernetes_security_falcosidekick_threat_detection

Video: https://www.youtube.com/watch?v=CGmw9UIvwAI

## Abstract

Jump right into Kubernetes security with this hands-on talk! Access a pre-configured Kali Purple VM loaded with Falcosidekick. Skip the setup and dive into real-world testing scenarios. Advance your skills in threat detection and ensure your cluster’s robust security in less than a lunchtime break.
