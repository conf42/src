# Shift Left, Shield Right: A DevSecOps Playbook for AI-Era CI/CD Pipelines

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Bhaskar Sawant](https://www.conf42.com/speaker_Bhaskar_Sawant) (Lead Engineer @ Senior Member, IEEE – Southeastern Michigan Section (SEM), Lead Engineer, Cornerstone Building Brands, USA). Page: https://www.conf42.com/DevOps_2026_Bhaskar_Sawant_security_automation_pipelines

Video: https://www.youtube.com/watch?v=Idx2HgGgMsc

## Abstract

AI-driven development changes your pipeline attack surface. This talk shows a practical blueprint for securing CI/CD—from code to containers—without slowing delivery. Real threats, real patterns, real fixes that DevOps teams can apply immediately.
