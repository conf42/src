# Ballerina Unleashed: Open Source Mastery in Cloud-Native Integration

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Anupama Pathirage](https://www.conf42.com/speaker_Anupama_Pathirage) (Director, Head of Engineering - Integration @ WSO2). Page: https://www.conf42.com/Kube_Native_2025_Anupama_Pathirage_ballerina_integration_opensource

Video: https://www.youtube.com/watch?v=5WOoGTRU4IQ

## Abstract

In today’s cloud-driven world, deployment is an integral part of development. Ballerina, an open-source language, simplifies this by integrating cloud-related constructs directly into code. This session explores Ballerina and how its built-in cloud support streamlines the journey from code to cloud.
