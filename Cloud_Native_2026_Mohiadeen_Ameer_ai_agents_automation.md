# Event-Driven Validation for Cloud-Native Resilience

A talk at [Conf42 Cloud Native 2026](https://www.conf42.com/cloud2026) by [Mohiadeen Ameer](https://www.conf42.com/speaker_Mohiadeen_Ameer) (Software Principal Engineer @ Dell Technologies). Page: https://www.conf42.com/Cloud_Native_2026_Mohiadeen_Ameer_ai_agents_automation

Video: https://www.youtube.com/watch?v=SfrSXgPmqDM

## Abstract

Modern healthcare platforms run on complex cloud-native ecosystems composed of microservices, APIs, containers, and distributed data pipelines. In such environments, reliability directly impacts operational continuity and regulatory compliance. Traditional validation approaches, manual, periodic, and reactive, cannot scale with the velocity and interdependencies of Kubernetes-based systems. This session introduces SupportPlus, an event-driven automation framework designed to embed continuous validation into cloud-native architectures. Built on microservices, serverless components, and Azure Kubernetes Service (AKS), the platform ingests high-volume event streams and executes parallel validation workflows across services, APIs, and data layers. Using metadata-driven rules and distributed orchestration patterns, the framework enables real-time detection, automated remediation, and observable control loops within containerized environments. Enterprise-scale deployment demonstrates measurable improvements in system availability, incident resolution time, and operational efficiency, while automated compliance and security checks convert audit readiness into a continuous byproduct of the platform. By unifying validation, monitoring, and remediation within a Kubernetes-native, event-driven architecture, this approach provides a scalable blueprint for engineering resilient, self-healing cloud-native systems in regulated and mission-critical environments.
