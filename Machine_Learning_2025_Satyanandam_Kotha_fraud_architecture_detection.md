A talk at [Conf42 Machine Learning 2025](https://www.conf42.com/ml2025) by [Satyanandam Kotha](https://www.conf42.com/speaker_Satyanandam_Kotha) (JawaharLal Nehru Technological University). Page: https://www.conf42.com/Machine_Learning_2025_Satyanandam_Kotha_fraud_architecture_detection

## Abstract

Discover how we built a real-time fraud detection system that catches fake reviews in milliseconds with 94% precision. Our hybrid architecture using streaming pipelines and graph neural networks scales to billions of interactions while maintaining strong privacy guarantees.
