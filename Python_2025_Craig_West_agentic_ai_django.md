A talk at [Conf42 Python 2025](https://www.conf42.com/python2025) by [Craig West](https://www.conf42.com/speaker_Craig_West) (Backend Pythonista). Page: https://www.conf42.com/Python_2025_Craig_West_agentic_ai_django

## Abstract

The use of AI and AI Agents in everyday Django can be viewed as `AI as API` where we can create on the Django side powerful agentic APIs.
