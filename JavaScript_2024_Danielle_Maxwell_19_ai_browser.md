# AI with JS: The Future is on the Browser

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Danielle Maxwell](https://www.conf42.com/speaker_Danielle_Maxwell) (Junior Distributed Systems Engineer @ Rotational Labs). Page: https://www.conf42.com/JavaScript_2024_Danielle_Maxwell_19_ai_browser

Video: https://www.youtube.com/watch?v=nqRYT-FR0W4

## Abstract

JavaScript programmers don't have to learn Python for machine learning. Learn how to use libraries like Transformers.js and TensorFlow.js in the browser to develop a wide range of AI applications.
