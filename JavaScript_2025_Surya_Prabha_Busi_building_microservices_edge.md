# Building the Future: Microservices, Edge & Cloud Innovation at Scale

A talk at [Conf42 JavaScript 2025](https://www.conf42.com/js2025) by [Surya Prabha Busi](https://www.conf42.com/speaker_Surya_Prabha_Busi) (Technical Lead @ Ford Credit). Page: https://www.conf42.com/JavaScript_2025_Surya_Prabha_Busi_building_microservices_edge

Video: https://www.youtube.com/watch?v=mZn4e0390no

## Abstract

Unlock the power of JavaScript in next-gen cloud ecosystems! Explore how microservices, edge, serverless, and quantum tech are reshaping app architecture. Packed with real-world data, this talk delivers practical strategies for scalable, future-ready systems.
