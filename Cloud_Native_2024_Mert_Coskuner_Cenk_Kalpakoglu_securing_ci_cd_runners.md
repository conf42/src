# Securing CI/CD runners through eBPF agent

A talk at [Conf42 Cloud Native 2024](https://www.conf42.com/cloud2024) by [Mert Coskuner](https://www.conf42.com/speaker_Mert_Coskuner) (Principal Product Security Engineer @ Yahoo) and [Cenk Kalpakoglu](https://www.conf42.com/speaker_Cenk_Kalpakoglu) (CEO & Co-Founder @ Kondukto). Page: https://www.conf42.com/Cloud_Native_2024_Mert_Coskuner_Cenk_Kalpakoglu_securing_ci_cd_runners

Video: https://www.youtube.com/watch?v=UbwK8KDHUS8

## Abstract

In this presentation, we will share some of our observations through showing different flavors of attack on possible development pipelines and introduce a tool to detect them.

## Key takeaways

- Today we will be talking about CI CD tool that we developed to secure runners using Berkeley packet filters. There are a lot of malicious application in the wild which dramatically increased throughout the years. Common attack vectors for attackers to achieve this are vulnerable packages and compromised pipeline tools.

- Nordic career based threat group recently published NPM package called execution timer sync. Package aims to steal the victims login credentials and passwords from the browsers. Also has a python script capability to further the compromise. We decided to develop our own tooling, which is also open source called control.

- EBPF technology is a way to write kernel level applications without literally writing or compiling anything in the kernel. The tool will basically run any newer Linux kernels which most of the Ci CD runners will apply. The aim is to develop a full fledged open source ci CD security solutions with EBPF power.
