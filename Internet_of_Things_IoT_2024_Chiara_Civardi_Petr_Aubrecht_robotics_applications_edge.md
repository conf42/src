# At the Edge of Robotic Applications

A talk at [Conf42 Internet of Things (IoT) 2024](https://www.conf42.com/iot2024) by [Chiara Civardi](https://www.conf42.com/speaker_Chiara_Civardi) (Product Marketer @ Payara Services Ltd) and [Petr Aubrecht](https://www.conf42.com/speaker_Petr_Aubrecht) (Software Engineer @ Payara Services Ltd). Page: https://www.conf42.com/Internet_of_Things_IoT_2024_Chiara_Civardi_Petr_Aubrecht_robotics_applications_edge

Video: https://www.youtube.com/watch?v=CAXEaXLutSc

## Abstract

This talk is crucial as it addresses the growing need for efficient data handling in robotics. It showcases how edge computing can support the broader adoption of robotic systems, overcoming latency and network issues, ultimately ensuring real-time data processing and improved robotic performance.
