# Zero Service Desk: Applying Machine Learning for Autonomous IT Support

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Anu Arora](https://www.conf42.com/speaker_Anu_Arora) (Director, Enterprise Systems Managenent @ ServiceNow). Page: https://www.conf42.com/Machine_Learning_2026_Anu_Arora_personalization_recommendation_platforms

Video: https://www.youtube.com/watch?v=Y-HCcRIr8Vg

## Abstract

What if IT support could fix issues before users report them? Learn how machine learning, conversational AI, and automation enable a Zero Service Desk eliminating tickets, predicting incidents, and delivering autonomous, self-service IT at scale.
