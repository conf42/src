# Build ML Workflows with Codex, Flyte, and MCP

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Phoebe Wang](https://www.conf42.com/speaker_Phoebe_Wang) (Member of Technical Staff @ OpenAI). Page: https://www.conf42.com/MLOps_2026_Phoebe_Wang_codex_flyte_mcp

## Abstract

AI coding tools can write ML code, but reliable execution still needs orchestration. This talk shows how to connect Codex to Flyte through MCP for a reproducible training or evaluation workflow.  I will talk about how OpenAI hosts Flyte for internal training, and how we developed MCP for integration with Codex.  Attendees will leave with a practical workflow pattern and a checklist for debugging, reproducibility, and safe execution.
