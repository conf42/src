# Beyond the Claw: Building Your Personal Coding Agent

A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Erik Hanchett](https://www.conf42.com/speaker_Erik_Hanchett) (Senior Developer Advocate @ AWS). Page: https://www.conf42.com/Platform_Engineering_2026_Erik_Hanchett_coding_agent_claw

Video: https://www.youtube.com/watch?v=eGsJBIwkcN4

## Abstract

Like a Roomba for your code, AI agents can coordinate to clean things up, fix bugs, and add new features. They can also keep working 24/7 while you're focused on something else. In this session, we'll look at what AI agents can actually do today and how a "Claw" turns them into a persistent workspace that can use tools, remember context, and run scheduled tasks. We'll go beyond coding to see how the same setup can help with research, planning, reminders, and other personal-assistant work. Along the way, we'll cover the current landscape, where these systems still fall short, and the approvals and guardrails that keep them useful. You'll leave with practical and fun ways to start using one without having to build everything from scratch.
