# No Wallet, No Problem: How JSON Web Tokens Define the Future of Mobile Driver's License

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Rizel Scarlett](https://www.conf42.com/speaker_Rizel_Scarlett) (Staff Developer Advocate @ TBD (Block)). Page: https://www.conf42.com/JavaScript_2024_Rizel_Scarlett_56_jsonwebtokens_mobile_security

## Abstract

Explore the rise of digital wallets, mobile driver's licenses, and contactless payments. Learn how to build your first Verifiable Credentials; cryptographic methods represented as JSON Web Tokens are revolutionizing identity verification.
