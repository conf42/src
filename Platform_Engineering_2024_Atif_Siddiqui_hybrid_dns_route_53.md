# Conquering Hybrid DNS with Route 53 Resolver

A talk at [Conf42 Platform Engineering 2024](https://www.conf42.com/platform2024) by [Atif Siddiqui](https://www.conf42.com/speaker_Atif_Siddiqui) (Senior Principal Software Engineer @ Silicon Valley Bank). Page: https://www.conf42.com/Platform_Engineering_2024_Atif_Siddiqui_hybrid_dns_route_53

Video: https://www.youtube.com/watch?v=udSdbOzlLLM

## Abstract

Nobody cares about DNS until it stops working. As platform engineers, we should accept this prevailing apathy. At the same time, building a robust Cloud (AWS) platform that addresses DNS management over a hybrid network remains a crucial tenet in sustaining this omnipresent apathy.
