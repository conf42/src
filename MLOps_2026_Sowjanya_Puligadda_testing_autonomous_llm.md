# Building Reliable LLM-Powered Autonomous Testing for Modern MLOps

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Sowjanya Puligadda](https://www.conf42.com/speaker_Sowjanya_Puligadda) (Senior Engineering Manager @ Uber). Page: https://www.conf42.com/MLOps_2026_Sowjanya_Puligadda_testing_autonomous_llm

## Abstract

As software systems become more complex, engineering teams need testing approaches that can scale with rapid development cycles and evolving application architectures. Traditional automation frameworks based on hardcoded locators and deterministic scripts often require significant maintenance effort, making it difficult to support continuous delivery at enterprise scale.  This session presents Autonomous Cognitive Navigation (ACN), a Natural Language Based (NLB) generative framework designed to make software testing more adaptive, reliable, and easier to maintain. ACN applies Large Language Models to interpret application states, reason through workflows, and execute complex end-to-end testing scenarios using natural language instructions instead of fragile test scripts.  The talk explores the architecture and engineering decisions behind ACN, including its State-Aware Reasoning Loop, Persistent Temporal Action Memory, Semantic Canonicalization approach, and multimodal end-state verification capabilities. These components address common challenges in AI-driven automation, such as maintaining context across long workflows, reducing unnecessary processing of UI information, and validating outcomes despite application changes.  The session also shares practical results from applying this approach across thousands of localized application variants and more than 70 languages. ACN achieved a 95% reliability rate while reducing new test flow onboarding efforts from 120 hours of manual scripting to under 4 hours of natural language definition.  Attendees will learn how LLM-based automation can be designed, evaluated, and integrated into modern engineering workflows to improve testing reliability, reduce maintenance overhead, and support scalable software delivery. The session is intended for MLOps engineers, developers, QA practitioners, and technical leaders interested in applying AI capabilities to real-world software operations.
