# Modern API Gateways: Data-Driven Reliability for Microservices & Serverless

A talk at [Conf42 Incident Management 2025](https://www.conf42.com/im2025) by [Vijaykumar Pasunoori](https://www.conf42.com/speaker_Vijaykumar_Pasunoori) (Technical Lead @ Valet Living). Page: https://www.conf42.com/Incident_Management_2025_Vijaykumar_Pasunoori_apigateways_microservices_serverless

Video: https://www.youtube.com/watch?v=q3htL6WHKdo

## Abstract

Discover how modern API gateways power incident detection, resilience, and rapid recovery in microservices and serverless systems. Backed by real-world data, this talk reveals performance gains, AI-powered routing, and edge strategies that keep systems stable at scale.
