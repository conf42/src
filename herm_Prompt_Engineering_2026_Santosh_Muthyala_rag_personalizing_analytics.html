    Abstract

    RAG can reduce hallucinated responses by over 60% compared with non-retrieval baselines, yet enterprise analytics systems often provide the same retrieval and response experience regardless of a user’s expertise, role, or objective. This session explores how prompt-driven personalization can make enterprise RAG systems more useful for real-world analytics workflows. The architecture combines three components: a User Profile Store, a Multi-Index Retrieval System, and a Personalized Generation Layer. Retrieval uses five specialized indices covering schemas, metric definitions, past queries, documentation, and curated SQL examples. Personalized re-ranking combines semantic similarity, user relevance, and recency, building on research reporting 10% to 31% improvements in mean average precision depending on query type. The session demonstrates how retrieval context and generation behavior can adapt for three analyst personas. Senior data engineers can receive SQL-first responses, business analysts can receive narrative interpretations, and product managers can receive concise KPI-oriented summaries. Drawing from production experience with a comparable system spanning SQL query history, dashboards, real-time analytics, and code notebooks at a billion-user-scale technology platform, the session also presents practical evaluation methods for retrieval personalization, response depth, format appropriateness, adaptation speed, and stale-profile detection.
