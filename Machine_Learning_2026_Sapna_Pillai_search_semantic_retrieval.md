# Governing Data Sovereignty in Distributed Multi-Cloud Machine Learning Systems

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Sapna Pillai](https://www.conf42.com/speaker_Sapna_Pillai) (Manager @ EY). Page: https://www.conf42.com/Machine_Learning_2026_Sapna_Pillai_search_semantic_retrieval

Video: https://www.youtube.com/watch?v=DU5LXy2xqAw

## Abstract

Discover how to build compliant, scalable multi-cloud ML systems amid rapidly evolving global data sovereignty laws. Learn where governance breaks down, what regulators expect next, and how sovereign cloud, zero-trust, and automation can future-proof ML deployments.
