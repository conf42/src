# A lap around GitHub Dependabot, CodeQL and other built-in security features

A talk at [Conf42 DevSecOps 2025](https://www.conf42.com/devsecops2025) by [Peter De Tender](https://www.conf42.com/speaker_Peter_De_Tender) (Business Program Manager - Lead Technical Trainer @ Microsoft). Page: https://www.conf42.com/DevSecOps_2025_Peter_De_Tender_github_dependabot_codeql

## Abstract

Like any other development process, security should be at the forefront of the dev cycle. That's where GitHub provides built-in solutions with Dependabot, CodeQL and several others. Learn in this session how to enable security features to protect code from vulnerabilities, full demos, no slides...
