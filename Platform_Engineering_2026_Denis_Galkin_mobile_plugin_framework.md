# Building an Internal Mobile Platform: A Plugin-Based Dev Mode Framework

A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Denis Galkin](https://www.conf42.com/speaker_Denis_Galkin) (Senior Android Engineer @ Robofinance). Page: https://www.conf42.com/Platform_Engineering_2026_Denis_Galkin_mobile_plugin_framework

Video: https://www.youtube.com/watch?v=pptgG5RPpgg

## Abstract

As mobile products scale, internal developer tools multiply rapidly—feature toggles, environment switchers, mock push generators, diagnostic screens, and dynamic API endpoints. Initially built ad-hoc, these utilities become scattered across debug menus and hidden gestures, causing friction for developers, QA engineers, and analysts across projects. In this talk, Denis Galkin presents the architecture of a unified, plugin-based Dev Mode framework designed as an internal platform product. Drawing from real-world fintech application infrastructure, Denis breaks down the separation of concerns between framework and product code: the core framework handles activation UI, routing (via Navigation 3), and plugin registration contracts, while individual feature teams retain full autonomy over plugin business logic. Listeners will learn how standardizing internal tooling as a reusable SDK improves cross-application consistency, accelerates QA workflows, and reduces developer friction.
