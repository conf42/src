# Application Resilience - Whose Job Is It Anyway?

A talk at [Conf42 Site Reliability Engineering (SRE) 2025](https://www.conf42.com/sre2025) by [Veliswa Boya](https://www.conf42.com/speaker_Veliswa_Boya) (Senior Developer Advocate @ AWS). Page: https://www.conf42.com/Site_Reliability_Engineering_SRE_2025_Veliswa_Boya_application_resilience_whose

Video: https://www.youtube.com/watch?v=LhjRCaQAVJc

## Abstract

Is it possible for application resilience and innovation to co-exist? In this talk, we discuss team cultural changes and technical considerations during software development that ensure the co-existence of application resilience and innovation?
