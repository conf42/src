# Designing a Self-Healing Ops Platform: Telemetry, RAG, and Confidence-Gated AI Agents

A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Madhu Chenna](https://www.conf42.com/speaker_Madhu_Chenna) (Senior Manager @ Electronic Arts). Page: https://www.conf42.com/Platform_Engineering_2026_Madhu_Chenna_healing_rag_telemetry

Video: https://www.youtube.com/watch?v=3SLIcosY9WY

## Abstract

Enterprise IT platforms often combine monitoring, endpoint management, and ITSM tools that never talk to each other. The result is a support model that stays reactive, even though up to 40% of Level-1 demand stems from issues existing telemetry could anticipate. This talk breaks down the Autonomous Digital Operations Framework (ADOF), a conceptual six-layer reference architecture, layer by layer. It covers: How endpoint telemetry and ITSM data are unified into one signal layer How Retrieval-Augmented Generation (RAG) gives agents access to enterprise knowledge How six specialized agents divide responsibility, including Incident Prediction, Asset Health, and Procurement Intelligence The core design decision is a confidence gate. Composite scores for enterprise health, business impact, and automation confidence decide whether an agent executes a fix (above 85%) or routes it for human approval (below 60%). A five-level maturity model sets how autonomy expands over time. ADOF is proposed for future validation, with illustrative targets such as up to a 40% reduction in repetitive Level-1 requests. Viewers will leave with a reference architecture and practical design patterns for building proactive, governed automation into their own platforms.
