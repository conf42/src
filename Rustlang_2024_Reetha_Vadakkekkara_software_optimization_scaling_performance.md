# Software Performance Optimization and Scaling

A talk at [Conf42 Rustlang 2024](https://www.conf42.com/rustlang2024) by [Reetha Vadakkekkara](https://www.conf42.com/speaker_Reetha_Vadakkekkara) (Azure Solutions Architect @ Tata Consultancy Services). Page: https://www.conf42.com/Rustlang_2024_Reetha_Vadakkekkara_software_optimization_scaling_performance

Video: https://www.youtube.com/watch?v=_-oBwD1gxzQ

## Abstract

I will show how to troubleshoot a software application, identifying performance bottlenecks, fixing them, and scaling the application. I’ll also cover how to make a software application globally available, ensure high responsiveness, handle disaster recovery, and optimize costs.
