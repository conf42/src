# Codeless Generative AI Pipelines: Prompt Automation

A talk at [Conf42 Prompt Engineering 2024](https://www.conf42.com/prompt2024) by [Tim Spann](https://www.conf42.com/speaker_Tim_Spann) (Principal Developer Advocate @ Zilliz). Page: https://www.conf42.com/Prompt_Engineering_2024_Tim_Spann_codeless_ai_automation

Video: https://www.youtube.com/watch?v=n3YWbT_oVVc

## Abstract

By utilizing a real-time streaming tool such as Apache NiFi, you can automate all of your prompt building and make data engineering for GenAI a snap.
