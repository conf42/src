    Abstract

    Guardrail metrics are usually built for one rollout shape — a fixed percentage, a fixed segment. But targeting rules change mid-flight: a flag expands to new cohorts, a canary widens, an experiment’s exposure shifts after the guardrail was already calibrated. This session asks whether adaptive statistical bounds can stay valid across that kind of drift, without being re-derived every time a rollout configuration changes. Using a rigorous, multi-decade financial dataset as a stress-test proxy — U.S. Treasury yield data, chosen for its long out-of-sample history and well-documented regime shifts — the study compares static (Gaussian) bounds, rolling recalibration, adaptive conformal methods, and bounds calibrated to a fixed, predefined set of exposure scenarios. Each approach is scored not just on average accuracy but on whether its misses cluster in time — the same failure mode that turns a guardrail from “safe” into “quietly broken” during a bad rollout window. The results show a real tradeoff. A single guardrail built to cover every possible exposure shape closes the average-accuracy gap but still produces clustered failures during regime change — false confidence at exactly the moment a rollout is riskiest. A guardrail scoped to a known, bounded set of exposure scenarios is tighter and more reliable within that scope, but breaks its guarantee the moment a genuinely new configuration appears. The talk lands on a practical two-layer architecture: a broad, reusable guardrail for exposures you haven’t anticipated, paired with a narrower, sharper guardrail for exposures you have. Attendees leave with a concrete framework for deciding when a guardrail can be trusted to generalize — and when it needs to be re-scoped as flags evolve.
