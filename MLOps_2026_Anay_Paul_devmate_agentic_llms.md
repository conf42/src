# Operationalizing Agentic LLMs: Building and Evaluating DevMate at Scale

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Anay Paul](https://www.conf42.com/speaker_Anay_Paul) (Arizona state university @ stealth). Page: https://www.conf42.com/MLOps_2026_Anay_Paul_devmate_agentic_llms

## Abstract

Moving agentic LLM systems from experimentation into real developer workflows requires more than capable models. It requires scalable orchestration, continuous evaluation, observability, and reliable feedback loops. This session explores DevMate, a centralized agentic LLM platform designed to support developer workflows across complex Android Open Source Project codebases at Meta.  DevMate combines static code understanding with dynamic contextual signals to support agentic tasks including code transformation, debugging assistance, and architectural reasoning. The session examines the architecture behind these workflows and the engineering considerations involved in operating them consistently across diverse development scenarios.  A central focus is DevMate's evaluation infrastructure, which uses graders, benchmarking pipelines, and feedback loops to assess model outputs, compare performance across tasks, and align model behavior with developer expectations. By embedding evaluation and observability into the platform, teams can make improvements measurable and reproducible while maintaining quality standards.  Attendees will gain practical insights into designing agentic LLM platforms, building evaluation pipelines, monitoring model behavior, and balancing autonomy, reliability, and developer trust in production-oriented AI workflows.
