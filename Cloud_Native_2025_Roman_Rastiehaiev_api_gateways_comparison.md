# Navigating the World of API Gateways: A Comparative Analysis of Open Source Solutions

A talk at [Conf42 Cloud Native 2025](https://www.conf42.com/cloud2025) by [Roman Rastiehaiev](https://www.conf42.com/speaker_Roman_Rastiehaiev) (Software Engineer @ HiBob). Page: https://www.conf42.com/Cloud_Native_2025_Roman_Rastiehaiev_api_gateways_comparison

Video: https://www.youtube.com/watch?v=UtCwgo7hVQs

## Abstract

This talk offers a comparative analysis of top open-source API gateways—like Kong, Traefik, and Envoy—helping you choose the right solution for scalable and secure API management in cloud-native environments.
