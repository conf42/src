# Aggressive LLMs Optimization: Making Them Work on Tiny Devices

A talk at [Conf42 Machine Learning 2025](https://www.conf42.com/ml2025) by [Max Navrotsky](https://www.conf42.com/speaker_Max_Navrotsky) (Senior Software Engineer @ VGS) and [Oleksandr Gordieiev](https://www.conf42.com/speaker_Oleksandr_Gordieiev) (Professor at Software Engineering Department @ Lutsk National Technical University). Page: https://www.conf42.com/Machine_Learning_2025_Max_Navrotsky_Oleksandr_Gordieiev_llms_optimization_devices

Video: https://www.youtube.com/watch?v=85k01nwkN5s

## Abstract

Discover how to shrink GPT‑2 for ultra‑weak hardware without sacrificing performance! We reveal how pruning, quantization, and fine‑tuning can unlock big large language model (LLM) power in tiny form.
