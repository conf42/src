# From Health Data to Action: Building AI Agents That Observe, Reason, and Intervene

A talk at [Conf42 AI Agents 2026](https://www.conf42.com/agents2026) by [Nick Rezaee](https://www.conf42.com/speaker_Nick_Rezaee) (Software Engineer @ Harvard University). Page: https://www.conf42.com/AI_Agents_2026_Nick_Rezaee_health_wearables_intervene

Video: https://www.youtube.com/watch?v=tyLJAIzIH5c

## Abstract

Most personal health technology ends at the dashboard. It collects data, calculates a few metrics, and tells you what already happened.  AI agents make it possible to do something with that information.  In this talk, I’ll show how an agent can use data from wearables, phones, computers, and other personal data sources to look for patterns over time and decide when a small intervention, such as a notification, might actually be useful.  The important part is that the agent does not start from scratch every day. It keeps track of what it has seen before, what interventions it has tried, and what happened afterward. For example: Does staying on the computer late tend to be followed by worse sleep? If the agent sends a reminder to wind down, does the person actually do it? Does their sleep improve? And if it does not, should the agent try something different next time?  I’ll cover how to give the agent useful context and memory, keep analysis separate from action, limit what the agent is allowed to do, and evaluate whether its interventions seem to be helping. I’ll also talk about one of the biggest practical problems with this kind of system: preventing it from becoming an annoying notification generator that thinks every pattern it finds is meaningful.  The goal is not to build an AI doctor. The goal is to show how an agent can move beyond answering prompts and become a system that watches what happens in the real world, takes small actions, learns from the results, and changes what it does over time.  Attendees will leave with a practical architecture they can adapt to their own projects, whether they are working on health, productivity, behavior change, or another setting where an agent can learn from the consequences of its own actions.
