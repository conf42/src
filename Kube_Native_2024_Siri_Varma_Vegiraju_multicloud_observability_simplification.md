# Simplifying Multi-Cloud Observability

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Siri Varma Vegiraju](https://www.conf42.com/speaker_Siri_Varma_Vegiraju) (Software Development Engineer @ Microsoft). Page: https://www.conf42.com/Kube_Native_2024_Siri_Varma_Vegiraju_multicloud_observability_simplification

Video: https://www.youtube.com/watch?v=9tXkVHqOnqg

## Abstract

Managing Observability in multi-cloud is challenging. This talk emphasizes the need for standardized, vendor-agnostic approaches to ensure scalable and usable observability. Learn how standard schemas and open source tools can enhance visibility and resilience in multi-cloud deployments.
