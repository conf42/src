## Abstract

Enterprise AI is moving beyond isolated text generation toward autonomous agents that can execute complex operational workflows, from real-time inventory placement to enterprise rewards orchestration. But most traditional data architectures were built for reporting and analytics, not for autonomous decision-making. In agentic systems, stale records, near-duplicate entities, inconsistent identifiers, or data drift can trigger serious downstream errors when decisions are executed directly across business-critical systems.  This session explores how Master Data Management must evolve for the agentic enterprise. Rather than serving only as a batch-processed analytics foundation, MDM must become an action-grade, immutable contract layer that supports reliable, real-time decisioning across operational workflows.  Drawing on experience building enterprise master data hubs, including a global system orchestration framework spanning 38,000 retail locations, the presentation will examine the architectural and strategic decisions required to create a stable data substrate for enterprise AI agents. Attendees will learn practical approaches for implementing sub-second match-and-survive functions, real-time routing, and event-driven orchestration using AWS Lambda, DynamoDB, and EventBridge.  The session will also cover idempotent workflow design, versioned data contracts, event-driven fan-out patterns, identity resolution strategies, and structural approaches for reducing data drift when autonomous agents interact with systems of record.  Designed for enterprise architects, data leaders, AI platform teams, and technology decision-makers, this session provides a practical blueprint for re-architecting MDM for action-oriented AI environments where data quality, entity resolution, and real-time routing directly shape operational outcomes.
