# Swarming LLM Agents for Real-Time Market Insight in Cloud-Native Trading Systems

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Kiran Purushotham](https://www.conf42.com/speaker_Kiran_Purushotham) (Executive Director, Sr. Principal Architect / Head of Architecture @ JPMorgan Chase). Page: https://www.conf42.com/Kube_Native_2025_Kiran_Purushotham_trading_llm_insight

Video: https://www.youtube.com/watch?v=drry36s-cu4

## Abstract

Discover how swarms of LLM agents running on Kubernetes are transforming real-time market prediction. Learn how our cloud-native SAFSO system achieves lightning-fast sentiment analysis, 95%+ forecast accuracy, and 21% annual returns all while preserving data privacy at scale.
