# How Kernel Programming Escaped the Kernel

A talk at [Conf42 Observability 2026](https://www.conf42.com/obs2026) by [Anais Dotis](https://www.conf42.com/speaker_Anais_Dotis) (Developer Advocate @ groundcover). Page: https://www.conf42.com/Observability_2026_Anais_Dotis_ebpf_linux_networking

Video: https://www.youtube.com/watch?v=0EwUeOLz3DY

## Abstract

eBPF started as a way to make Linux networking faster. Now it's revolutionizing everything from security to observability to performance optimization, and most engineers don't even know it exists. This talk cuts through the hype to show you what eBPF actually is and why it matters for modern engineering. We'll explore how this kernel technology enables impossible things: zero-overhead monitoring, runtime security enforcement, and network optimization that works at line speed. You'll see eBPF in action across different domains, network monitoring, system call tracing and “encrypted traffic debugging”. From Kubernetes networking to serverless performance, eBPF is quietly powering solutions that seemed impossible just a few years ago. You will be introduced to some useful eBPF scripts that will assist you in your daily tasks, will understand where eBPF fits in your stack and how to start tinkering with it today. It will bee fun!
