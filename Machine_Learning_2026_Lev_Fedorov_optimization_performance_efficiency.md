# Making recommendations explainable

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Lev Fedorov](https://www.conf42.com/speaker_Lev_Fedorov) (Software Engineer @ Amazon). Page: https://www.conf42.com/Machine_Learning_2026_Lev_Fedorov_optimization_performance_efficiency

Video: https://www.youtube.com/watch?v=dqamvMp-sl8

## Abstract

How we turned a black-box recommender into a traceable, explainable ranking system in production: full recsys pipeline, per-user recommendation traces, and dashboards that product, safety and ML teams actually use.
