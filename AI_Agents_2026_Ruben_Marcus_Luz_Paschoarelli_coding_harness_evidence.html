    Abstract

    AI coding does not fail because models are weak. It fails because the system around them trusts the wrong evidence. I will show the harness I use to turn agent output into something shippable: short specs, isolated git worktrees, model routing by role, browser-based verification, screenshot gates, regression hunters, and cost controls. The same operating style powers Ralph Starter, my portfolio build pipeline, and the benchmark loops behind public #1 results. The point is not use more agents. The point is that builders should not grade their own work, a passing build is not proof of a good UI, and every keep decision needs a ruler. Attendees will leave with a practical blueprint for building agent loops that stop on evidence instead of confidence.
