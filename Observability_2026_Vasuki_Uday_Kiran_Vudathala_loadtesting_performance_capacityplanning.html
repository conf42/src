Automating peak readiness: turning observability signals into workload engineering insights

Video size:

Abstract

Building a realistic workload model for peak readiness is still surprisingly manual in most organizations. Developers are interviewed to reconstruct user journeys. Traffic dashboards are manually inspected to estimate peak periods. Concurrent users are approximated in spreadsheets. Multiple teams spend days assembling scenario distributions that are often still inaccurate once the load test begins. The problem is not effort. The problem is that the production truth already exists inside the observability platform — but most organizations lack a systematic way to extract and operationalize it. This session presents an observability-driven workload engineering framework that automatically transforms APM telemetry into production-grade workload models within minutes. Using telemetry from APM and analytics platforms such as New Relic, Dynatrace, AppDynamics, and Google Analytics, we demonstrate how to: • Identify true peak traffic periods from historical telemetry, • Derive real scenario distributions from production user journeys, • Calculate concurrency using session-based analysis derived directly from production telemetry, • Automatically assemble repeatable workload models for load testing and peak readiness exercises. The session includes live examples using NRQL and Dynatrace Real User Monitoring, while keeping the framework vendor-neutral and transferable across observability platforms. Rather than using observability only to explain incidents after they happen, this approach turns production telemetry into a proactive engineering instrument for anticipating and engineering for peak demand before it arrives.
