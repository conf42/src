A talk at [Conf42 Prompt Engineering 2026](https://www.conf42.com/prompt2026) by [Indika Wimalasuriya](https://www.conf42.com/speaker_Indika_Wimalasuriya) (Director - SRE, Observability @ Virtusa). ## Abstract

AI agents are moving from experimental demos to production systems, reasoning over data, invoking tools, interacting with applications, and taking actions on behalf of the business. As these systems become more autonomous, traditional application monitoring alone is no longer enough. Engineers need visibility into not only whether an agent is running, but also what it is doing, which tools it is invoking, how models are behaving, and what each interaction costs.  This session presents a practical approach to end-to-end observability for autonomous AI using Amazon Bedrock AgentCore and Datadog. We will walk through a production-style AI agent running on AWS and trace a user request across the complete execution path — from agent orchestration and model interactions to tool invocations, downstream AWS services, infrastructure, and application telemetry.  Using Datadog APM, LLM Observability, Infrastructure Monitoring, Logs, and OpenTelemetry-compatible telemetry from AgentCore, we will demonstrate how AI-specific signals can be correlated with traditional application and infrastructure telemetry in a single operational view.  The session will show how observability can help engineers understand agent behavior, identify failed or unexpected tool calls, investigate latency and errors, detect abnormal token and cost consumption, and establish operational guardrails for production AI workloads.  Attendees will leave with a practical reference architecture and an SRE-oriented methodology for moving from simply deploying AI agents to operating autonomous AI reliably at production scale.
