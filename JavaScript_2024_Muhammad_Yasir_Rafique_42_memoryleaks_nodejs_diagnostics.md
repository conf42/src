# Taming Memory Leaks in Node.js: A Deep Dive into Diagnostics and Solutions

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Muhammad Yasir Rafique](https://www.conf42.com/speaker_Muhammad_Yasir_Rafique) (Nodejs Backend Developer @ Find My Facility). Page: https://www.conf42.com/JavaScript_2024_Muhammad_Yasir_Rafique_42_memoryleaks_nodejs_diagnostics

Video: https://www.youtube.com/watch?v=A1zbvng3KtM

## Abstract

Tired of memory leaks in your Node.js apps? Join me to master essential tools and techniques to diagnose, fix, and prevent them. Learn how to use Chrome DevTools, Node’s --inspect, and profilers to keep your apps running smoothly and boost performance in production!
