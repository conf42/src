# Rust in Edge Computing: Enhancing Performance and Security

A talk at [Conf42 Rustlang 2024](https://www.conf42.com/rustlang2024) by [Venukumar Chirlawar](https://www.conf42.com/speaker_Venukumar_Chirlawar) (Senior Software Developer @ Amazon). Page: https://www.conf42.com/Rustlang_2024_Venukumar_Chirlawar_edge_computing_security

Video: https://www.youtube.com/watch?v=7OC86296Vls

## Abstract

In this presentation, we will explore the role of Rust in edge computing, emphasizing its unique advantages in terms of performance and security. Rust's memory safety features and concurrency model make it an excellent choice for edge applications, which often require high efficiency and robust protection against security vulnerabilities. We will delve into practical examples and case studies to illustrate how Rust can be effectively utilized in various edge computing scenarios.
