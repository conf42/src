# Cloud Testing Without the Wait: Transforming the Kubernetes development experience

A talk at [Conf42 Cloud Native 2025](https://www.conf42.com/cloud2025) by [Anita Ihuman](https://www.conf42.com/speaker_Anita_Ihuman) (Developer Advocate @ MetalBear). Page: https://www.conf42.com/Cloud_Native_2025_Anita_Ihuman_kubernetes_development_testing

Video: https://www.youtube.com/watch?v=K8Zk7jiOU4I

## Abstract

Imagine if you could shift left on your cloud testing and shorten the development loop from hours to seconds.
In this session,We’ll explore how remocal development can create realistic testing scenarios, enabling teams to uncover critical issues before they impact production.
