# Practical guide to testing Go services

A talk at [Conf42 Golang 2025](https://www.conf42.com/golang2025) by [Nikolay Kuznetsov](https://www.conf42.com/speaker_Nikolay_Kuznetsov) (Senior Golang Software Engineer @ Zalando). Page: https://www.conf42.com/Golang_2025_Nikolay_Kuznetsov_testing_go_services

Video: https://www.youtube.com/watch?v=AhfCgPbwjG4

## Abstract

Learn how to test each layer effectively—from databases with Testcontainers to service logic with mocks, and HTTP handlers with httptest. Discover essential tools like testify, mockery, go-cmp, and Localstack for AWS emulation.
