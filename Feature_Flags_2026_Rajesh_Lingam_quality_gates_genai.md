# Beyond On/Off: Using Quality Gates to Safely Release GenAI Features

A talk at [Conf42 Feature Flags 2026](https://www.conf42.com/featureflags2026) by [Rajesh Lingam](https://www.conf42.com/speaker_Rajesh_Lingam) (Senior Lead Technical AI Evaluation Specialist @ Adobe Inc). Page: https://www.conf42.com/Feature_Flags_2026_Rajesh_Lingam_quality_gates_genai

Video: https://www.youtube.com/watch?v=K88d8qp9zpM

## Abstract

Feature flags give engineering teams control over when software reaches users. But with Generative AI, controlling exposure is only part of the problem. A feature can be technically healthy while its answers become less accurate, grounded, safe, or performant.  In this talk, I’ll share an engineering approach for combining feature flags, automated AI evaluation, and quality gates to make GenAI releases safer and more measurable. Instead of treating evaluation as a manual exercise performed shortly before release, teams can continuously evaluate model and application behavior and use those signals to inform rollout decisions.  We’ll look at how automated evaluation pipelines can measure answer quality, grounding, safety, latency, and regression against established baselines; how quality thresholds can become release criteria; and how progressive rollout and feature flags provide a practical control plane when AI behavior changes unexpectedly.  Attendees will leave with a reusable pattern for moving from “is the feature enabled?” to “has the feature demonstrated that it is ready to be enabled?”
