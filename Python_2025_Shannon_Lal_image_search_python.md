# Hybrid Image Search in Python with Motor, MongoDB, and OpenAI

A talk at [Conf42 Python 2025](https://www.conf42.com/python2025) by [Shannon Lal](https://www.conf42.com/speaker_Shannon_Lal) (VP Technology and Engineering @ Designstripe). Page: https://www.conf42.com/Python_2025_Shannon_Lal_image_search_python

Video: https://www.youtube.com/watch?v=_wq6BP9Es10

## Abstract

At Designstripe, we revolutionized image search by combining traditional text search with AI-powered semantic search. This talk demonstrates how we implemented hybrid search using Python, MongoDB, and OpenAI, significantly improving search relevancy for our users.
