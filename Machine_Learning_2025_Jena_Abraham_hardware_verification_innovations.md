# Machine Learning Innovations in Hardware Verification for High-Speed Protocol Testing

A talk at [Conf42 Machine Learning 2025](https://www.conf42.com/ml2025) by [Jena Abraham](https://www.conf42.com/speaker_Jena_Abraham) (Senior Design Verification Engineer / Technical Program Manager @ Intel Corporation). Page: https://www.conf42.com/Machine_Learning_2025_Jena_Abraham_hardware_verification_innovations

Video: https://www.youtube.com/watch?v=-QL5tfqi9OM

## Abstract

Discover how AI transforms hardware verification! Our machine learning approach revolutionizes testing for PCIe Gen 5/6 and USB 4.0, slashing verification time while boosting coverage. Learn how AI-driven test generation and FPGA acceleration solve tomorrow's high-speed protocol challenges today.
