    Abstract

    Most agentic AI is theater. This is the inverse — a production agent orchestration pipeline that earned its 80% accuracy through engineering, not vibes. I built an AI pipeline using Claude Code and the Model Context Protocol (MCP) that runs at a Fortune 500 telecom and previously at a top-25 mobile consumer app. Three MCP servers — Confluence/Jira, a structured test-case repository, the automation codebase — let the model translate product requirements into Jira stories, test cases, and executable Appium/TypeScript code at ~80% accuracy. The talk is about the 20%: where agents drift, why orchestration patterns matter more than model choice, and why the human-in-the-loop PR gate is the feature that makes the system shippable. Five lessons that earned scars: don’t ask the model to do deterministic work — flaky detection drifts; constrain to a JSON schema or review time blows up 5x; the human PR gate is mandatory — a silent regression cost us a multi-week mess; measure quality before optimizing cost — we cut tokens 25% and hotfixes ticked up; don’t replace the existing automation runtime, layer agents on top. The takeaway: ~80% of generated automation runs the intended scenario without post-generation edits. The cheap-fail-to-expensive-fail ratio after guardrails is 4:1 (was 1:1 without). That ratio is the year of work behind this talk. Attendees leave with: a reference architecture for production agent orchestration, MCP integration patterns, a failure-mode catalog, and a 30/60/90-day adoption plan.
