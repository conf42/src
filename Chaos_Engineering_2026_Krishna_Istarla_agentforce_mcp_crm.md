# Securing Agentforce MCP Integrations Against Seven CRM Failure Risks

A talk at [Conf42 Chaos Engineering 2026](https://www.conf42.com/chaos2026) by [Krishna Istarla](https://www.conf42.com/speaker_Krishna_Istarla) (Senior Software Engineer @ Global Payments). Page: https://www.conf42.com/Chaos_Engineering_2026_Krishna_Istarla_agentforce_mcp_crm

## Abstract

Enterprise AI agents introduce security and reliability risks when untrusted CRM data influences automated decisions and tool execution. In Salesforce Agentforce deployments, customer-submitted case descriptions, knowledge articles, and account histories can become attack surfaces that protocol-level MCP defenses alone cannot adequately protect.  This session examines seven CRM-native integration risks: case description injection, knowledge base poisoning, account history manipulation, SOQL injection through MCP query parameters, tool result manipulation, data exfiltration through webhooks, and permission escalation through tool chaining.  Attendees will explore how these risks can compromise agent behavior and how Salesforce-native controls help reduce exposure. Practical mitigation approaches include Agent Script deterministic gates, Apex wrappers with parameterized SOQL and allowlists, Connected App outbound restrictions, tool-chain depth limits, and Shield monitoring.  The session organizes these safeguards into four engineering layers: input validation, reasoning isolation, execution governance, and output monitoring. Through concrete CRM integration scenarios, attendees will learn how to identify potential failure paths, strengthen execution controls, and improve the security and reliability of Agentforce deployments.
