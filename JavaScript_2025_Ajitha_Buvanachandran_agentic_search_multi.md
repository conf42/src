# Agentic Search with JavaScript: Multi-Agent Intelligence for Next-Gen Insights

A talk at [Conf42 JavaScript 2025](https://www.conf42.com/js2025) by [Ajitha Buvanachandran](https://www.conf42.com/speaker_Ajitha_Buvanachandran) (Anna University). Page: https://www.conf42.com/JavaScript_2025_Ajitha_Buvanachandran_agentic_search_multi

## Abstract

See how JavaScript powers the future of search: agentic systems that decompose queries, orchestrate AI agents, and deliver decision-ready insights. Move beyond retrieval to real intelligence with multi-agent architectures that scale with modern apps and enterprise data.
