# Mission: Performance Impossible – Real time chat webapp’s performance with 100k active users

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Mohammed Zubair Ahmed](https://www.conf42.com/speaker_Mohammed_Zubair_Ahmed) (Software Design Engineer @ Mattermost). Page: https://www.conf42.com/JavaScript_2024_Mohammed_Zubair_Ahmed_41_realtimechat_performance_100kusers

Video: https://www.youtube.com/watch?v=wzDVPtKodZI

## Abstract

Scaling Mattermost to support 100k active users meant tackling complex performance challenges. This talk provides a practical look at how we measured, validated, and improved Mattermost's performance for a better user experience.
