# Make Agents Observable: Tracing Decisions, Tool Calls and Recovery

A talk at [Conf42 Observability 2026](https://www.conf42.com/obs2026) by [Emerson Braun](https://www.conf42.com/speaker_Emerson_Braun) (Staff Engineer / Regional Director @ Plan A Technologies). Page: https://www.conf42.com/Observability_2026_Emerson_Braun_agents_llms_observability

Video: https://www.youtube.com/watch?v=ZKqDNqO-anM

## Abstract

AI agents can produce a confident final answer while hiding the most important part of the execution: what context they received, which decisions they made, which tools they called, and where the workflow started to drift. This talk presents an observability model for agentic systems that goes beyond application logs and model latency. We will follow a realistic agent execution from request to outcome and instrument the signals that make it explainable and operable: - context and instruction versions; - structured decisions and route selection; - tool calls, inputs, outputs, and validation results; - model, latency, token cost, retries, and failures; - policy checks, blocked actions, and human approvals; - final outcomes, fallbacks, and recovery attempts. Using an AgentsKit example, we will compare a deterministic path with an agentic path and show how a shared execution trace makes their behavior visible without relying on hidden chain-of-thought. We will also discuss privacy-aware telemetry: what to record, what to redact, and how to preserve useful evidence without collecting unnecessary secrets or personal data. The session closes with practical metrics and debugging patterns for production agents: task success rate, tool error rate, retry loops, escalation rate, cost per successful task, and time to diagnose a failed execution. Attendees will leave with a concrete checklist for instrumenting agent workflows and answering the question every production team eventually faces: did the agent fail, did a tool fail, or did we give the system the wrong context in the first place?
