# Mirror Mirror on My local machine

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Anita Ihuman](https://www.conf42.com/speaker_Anita_Ihuman) (Developer Advocate @ MetalBear). Page: https://www.conf42.com/Kube_Native_2024_Anita_Ihuman_local_machine_mirror_dev_environment

Video: https://www.youtube.com/watch?v=7JyQsPXh-uU

## Abstract

Developers do not need to deal with strenuous debugging cycles and slowed feedback loops due to rebuilds, redeployments, and network overhead in environments like Kubernetes anymore thanks to Remocal development
