# Designing for Failure: Practical Chaos Engineering in Cloud Systems

A talk at [Conf42 Chaos Engineering 2026](https://www.conf42.com/chaos2026) by [Emmanuela Opurum](https://www.conf42.com/speaker_Emmanuela_Opurum) (Solutions Architect @ SoftNet Technologies). Page: https://www.conf42.com/Chaos_Engineering_2026_Emmanuela_Opurum_failure_cloud_chaos

## Abstract

Modern cloud systems are distributed, complex, and inherently failure-prone. Yet most engineering teams still design for ideal conditions rather than real-world failure scenarios.  This talk explores chaos engineering as a practical discipline for improving system resilience in cloud-native architectures. Using real-world cloud architecture examples, we examine how controlled failure injection exposes hidden weaknesses before they impact production users.  We will cover:  What chaos engineering is (beyond theory) How to safely introduce failure in cloud environments (AWS/Kubernetes patterns) The role of observability in detecting and diagnosing system degradation Common architectural failure modes in distributed systems How to start implementing chaos experiments incrementally in real production systems  By the end, attendees will understand how to move from reactive incident response to proactive resilience engineering using structured chaos experiments grounded in real system design.
