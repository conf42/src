# Your Agent Works. Will It Survive Tomorrow? Operating LangGraph.js with skein-js

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Maina Wycliffe](https://www.conf42.com/speaker_Maina_Wycliffe) (Founder/Chief Builder @ Garatropic). Page: https://www.conf42.com/MLOps_2026_Maina_Wycliffe_langgraph_skein_agent

## Abstract

Your agent reviews a support ticket, proposes an action, and pauses for approval. The reviewer returns tomorrow. Meanwhile, your server has restarted, you’ve deployed a new version, and the submitting system has retried its request. The approval must still exist, the retry must resolve to the original work, and an operator needs to understand what happened. Building a useful agent is only the beginning of running a dependable service.  This talk introduces skein-js, an open-source, self-hosted TypeScript server runtime for LangGraph.js agents. LangGraph provides graph execution, checkpointing, and interrupts. skein-js supplies the infrastructure around those graphs: persistent API resources, background execution, streaming, and an operator console, while retaining existing LangGraph.js graphs and SDK clients.  Through an issue-triage demonstration, we’ll follow a workflow through duplicate submission, human approval, and a server restart. We’ll examine how Postgres persistence and Redis-backed background work support reliable execution, where idempotency guarantees end, and how telemetry helps explain failures. Attendees will leave with a concrete architecture for operating agents on infrastructure they control and failure scenarios they can use to evaluate any agent runtime.
