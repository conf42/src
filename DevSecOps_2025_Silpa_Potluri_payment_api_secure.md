# Securing Payment Gateway Evolution: DevSecOps in Microservices Migration

A talk at [Conf42 DevSecOps 2025](https://www.conf42.com/devsecops2025) by [Silpa Potluri](https://www.conf42.com/speaker_Silpa_Potluri) (Software Developer @ GoodLeap). Page: https://www.conf42.com/DevSecOps_2025_Silpa_Potluri_payment_api_secure

Video: https://www.youtube.com/watch?v=mBQhrJ3eS2s

## Abstract

Learn how payment gateways achieve rapid, secure deployments through DevSecOps practices, reducing security incidents 60% while maintaining PCI compliance and enabling daily releases in microservices architectures.
