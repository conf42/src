# Machine Learning–Driven Compliance Engines for Zero Trust Security

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Sudheer Kumar Aluvala](https://www.conf42.com/speaker_Sudheer_Kumar_Aluvala) (Client Delivery Director - Engineering @ HCL America). ## Abstract

Static compliance policies can’t keep up with Zero Trust. Learn how machine learning enables real-time, adaptive compliance by continuously learning from user behavior, endpoint telemetry, and threat intelligence turning compliance into an intelligent security control.
