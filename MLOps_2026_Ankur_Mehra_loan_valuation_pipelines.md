# Building Resilient MLOps Pipelines for Illiquid Loan Portfolio Valuation

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Ankur Mehra](https://www.conf42.com/speaker_Ankur_Mehra) (Independent Researcher @ Stealth). Page: https://www.conf42.com/MLOps_2026_Ankur_Mehra_loan_valuation_pipelines

## Abstract

Financial institutions rely on complex models to value mortgages, commercial loans, and other illiquid lending assets under changing market conditions. Moving these models into reliable production environments requires more than accurate calculations—it requires scalable pipelines, reproducibility, observability, and strong controls around data and model changes.  This session presents a practical MLOps architecture for building and operating resilient loan portfolio valuation systems. It explores how market data ingestion, configurable economic scenarios, prepayment assumptions, cash-flow models, and discounting workflows can be organized into repeatable valuation pipelines. The session examines versioning of data, model configurations, and assumptions so teams can reproduce historical valuations, investigate unexpected results, and safely introduce model updates.  The session also covers operational considerations including automated testing, pipeline monitoring, data lineage, failure handling, model validation, and auditability. Event-driven processing patterns are explored as a way to respond efficiently to changes in market data and portfolio positions while supporting scalable computation. Attendees will learn practical architectural principles for transforming financial valuation models into maintainable production systems where reliability, traceability, and reproducibility are treated as core MLOps requirements.
