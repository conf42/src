# Level up your react hooks

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Daniel Espino Garcia](https://www.conf42.com/speaker_Daniel_Espino_Garcia) (Software Design Engineer @ Mattermost). Page: https://www.conf42.com/JavaScript_2024_Daniel_Espino_Garcia_18_reacthooks_improvement_development

Video: https://www.youtube.com/watch?v=Hm1QM485u2s

## Abstract

Functional components on React introduced hooks, a completely different approach to how you deal with the component lifecycle.

In this talk we will discuss how they work in the inside, and how to take the most out of them, including a few tricks to level up your game.
