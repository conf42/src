# Defending the AI Factory: Practical Security Strategies for MLOps

A talk at [Conf42 MLOps 2026](https://www.conf42.com/mlops2026) by [Jose Manuel Ortega](https://www.conf42.com/speaker_Jose_Manuel_Ortega) (Security Researcher @ Alicante University). Page: https://www.conf42.com/MLOps_2026_Jose_Manuel_Ortega_security_factory_mlops

## Abstract

As machine learning models transition from experimental notebooks into critical production systems, they become primary targets for sophisticated cyberattacks. Standard DevOps security is no longer enough to protect the unique components of the machine learning lifecycle.  This intermediate-level talk dives deep into SecMLOps (Security in Machine Learning Operations), exploring how vulnerabilities manifest across the entire ML pipeline. Attendees will learn how to secure data ingestion pipelines against data poisoning, protect model registries from unauthorized tampering, mitigate supply chain risks in Python dependencies, and defend deployed endpoints against adversarial and extraction attacks. Through real-world architectural patterns and practical toolchains, this session provides actionable strategies to build resilient, secure, and compliant AI systems without stalling developer velocity.
