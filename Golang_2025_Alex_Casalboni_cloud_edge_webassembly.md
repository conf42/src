# From Cloud to Edge computing - Unleashing the power of WebAssembly at the edge

A talk at [Conf42 Golang 2025](https://www.conf42.com/golang2025) by [Alex Casalboni](https://www.conf42.com/speaker_Alex_Casalboni) (Developer Advocate @ Edgee). Page: https://www.conf42.com/Golang_2025_Alex_Casalboni_cloud_edge_webassembly

Video: https://www.youtube.com/watch?v=tp61nlI8DDw

## Abstract

Discover how WASM at the edge pushes beyond cloud limits, enabling low-latency, secure, and distributed computing. In this talk, we’ll explore Golang+Wasm patterns for edge deployments, covering performance, security, and real-world use cases that blend cloud and edge seamlessly.
