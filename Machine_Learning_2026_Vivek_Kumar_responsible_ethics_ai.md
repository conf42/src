# Applying Machine Learning to Performance Optimization in High-Volume Transaction Systems

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Vivek Kumar](https://www.conf42.com/speaker_Vivek_Kumar) (Acquisition Employee @ Majesco). Page: https://www.conf42.com/Machine_Learning_2026_Vivek_Kumar_responsible_ethics_ai

Video: https://www.youtube.com/watch?v=Dw8zO4qk6Qc

## Abstract

What if your transaction systems could predict performance issues before they happen? Learn how machine learning models use real-time telemetry to optimize scaling, reduce latency, and build self-adapting microservice platforms for high-volume workloads.
