# Chaos for Coding Agents: Deliberate Failure Modes Before They Hit Production Review

A talk at [Conf42 Chaos Engineering 2026](https://www.conf42.com/chaos2026) by [Sachin Hiriyanna](https://www.conf42.com/speaker_Sachin_Hiriyanna) (Staff Software Engineer @ Navan). Page: https://www.conf42.com/Chaos_Engineering_2026_Sachin_Hiriyanna_coding_agents_failure

## Abstract

Agents fail differently than services — silent wrongness, tool misuse, and cascading “helpful” changes. This talk adapts chaos thinking to agent workflows: inject bad tool results, revoke permissions mid-task, force prompt/skill regressions, and measure blast radius in review time and escape defects. How staff engineers design safe experiments so teams learn agent limits before customers do. For engineers who ship agents, not academic chaos tooling demos.
