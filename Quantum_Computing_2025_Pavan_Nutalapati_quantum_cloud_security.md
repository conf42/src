# Preparing for the Impact of Quantum Computing on Cloud Security

A talk at [Conf42 Quantum Computing 2025](https://www.conf42.com/quantum2025) by [Pavan Nutalapati](https://www.conf42.com/speaker_Pavan_Nutalapati). Page: https://www.conf42.com/Quantum_Computing_2025_Pavan_Nutalapati_quantum_cloud_security

Video: https://www.youtube.com/watch?v=m1veul-6zy0

## Abstract

Quantum computing is coming fast—and it threatens to break today’s encryption. This talk explores how it impacts cloud security and what you must do now to defend your data. Learn key risks, emerging standards, and how to build a quantum-safe strategy.
