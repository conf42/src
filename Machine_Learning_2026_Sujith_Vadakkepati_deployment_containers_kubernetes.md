# Explainable Hybrid RAG–LLM Framework for Dynamic Supplier Risk Intelligence

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Sujith Vadakkepati](https://www.conf42.com/speaker_Sujith_Vadakkepati) (Senior Principal Product Manager @ Oracle). Page: https://www.conf42.com/Machine_Learning_2026_Sujith_Vadakkepati_deployment_containers_kubernetes

Video: https://www.youtube.com/watch?v=5tzUA38kNN8

## Abstract

Discover how an explainable hybrid RAG–LLM system transforms supplier risk intelligence by fusing ERP data with real-time external signals. Learn to detect hidden financial, compliance, and ESG risks faster with transparent, auditable AI built for global supply chains.
