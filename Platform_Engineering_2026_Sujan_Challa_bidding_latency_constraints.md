# Platform Engineering for Real-Time Bidding Under Strict Latency Constraints

A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Sujan Challa](https://www.conf42.com/speaker_Sujan_Challa) (Senior Software Engineer @ Samsung Electronics America). Page: https://www.conf42.com/Platform_Engineering_2026_Sujan_Challa_bidding_latency_constraints

Video: https://www.youtube.com/watch?v=AocAtwN4hqs

## Abstract

Real-Time Bidding systems put platform engineering under extreme pressure. Each advertising opportunity must pass through targeting, decisioning, bidding, and response generation within a strict latency budget, while the underlying platform handles large volumes of concurrent traffic reliably. This session explores the platform engineering patterns behind production-grade RTB systems, focusing on how low-latency services can remain scalable, resilient, observable, and safe to evolve. We’ll examine a modular auction architecture spanning feature retrieval, targeting, decisioning, bid strategy, and response generation. The session explores latency budgets as architectural constraints, along with timeout and fallback mechanisms that prevent downstream dependencies from delaying critical request paths. It also covers practical approaches for evolving live infrastructure using traffic mirroring, controlled traffic splitting, progressive deployments, CI/CD automation, and production observability. Attendees will leave with practical architectural patterns for operating and modernizing latency-sensitive platforms while maintaining reliability and minimizing disruption to live traffic.
