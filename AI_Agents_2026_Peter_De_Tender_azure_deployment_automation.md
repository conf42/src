# What if you could deploy Azure end-to-end scenarios while sleeping?

A talk at [Conf42 AI Agents 2026](https://www.conf42.com/agents2026) by [Peter De Tender](https://www.conf42.com/speaker_Peter_De_Tender) (Senior Content Developer @ Microsoft). Page: https://www.conf42.com/AI_Agents_2026_Peter_De_Tender_azure_deployment_automation

Video: https://www.youtube.com/watch?v=4gDWlMCo11A

## Abstract

In my previous role as Technical Trainer at Microsoft, I had to build and deploy a new Azure scenario daily to make my workshops more engaging and reflective of real-customer scenarios. This turned into an Open Source project in 2025, with +75 scenarios to reuse. Building those scenarios was time-intensive, error-prone and just no fun. That's why I flipped it into a full agentic solution. That is still Open-Source for you to reuse and contribute to. If you manage Azure, or you just want to learn more about the platform with actual scenarios to deploy, but you don't want to build them manually, this session is for you!
