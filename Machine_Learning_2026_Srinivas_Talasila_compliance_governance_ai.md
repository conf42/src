# From Reliable Models to Resilient ML Platforms: Designing Secure, Highly Available Infrastructure for Production Machine Learning

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Srinivas Talasila](https://www.conf42.com/speaker_Srinivas_Talasila) (Director of Cloud Operations at SAP @ SAP). Page: https://www.conf42.com/Machine_Learning_2026_Srinivas_Talasila_compliance_governance_ai

Video: https://www.youtube.com/watch?v=rpNkCUPGb14

## Abstract

Production ML fails without resilient infrastructure. Learn how real-world teams redesigned compute platforms using HA, DR, and Zero Trust to keep training, inference, and data pipelines secure, available, and reliable at scale.
