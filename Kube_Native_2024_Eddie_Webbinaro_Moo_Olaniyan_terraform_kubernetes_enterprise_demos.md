# How CircleCI's Field Engineer team use custom Terraform modules and K8s to deliver globally distributed & highly tailored enterprise demos

A talk at [Conf42 Kube Native 2024](https://www.conf42.com/kubenative2024) by [Eddie Webbinaro](https://www.conf42.com/speaker_Eddie_Webbinaro) (Senior Director, Head of Field Engineering @ CircleCI) and [Moo Olaniyan](https://www.conf42.com/speaker_Moo_Olaniyan) (Senior Field Engineer @ CircleCI). Page: https://www.conf42.com/Kube_Native_2024_Eddie_Webbinaro_Moo_Olaniyan_terraform_kubernetes_enterprise_demos

Video: https://www.youtube.com/watch?v=ig9HvwHxD-s

## Abstract

Fully automated "customer enterprise reference architecture" deployed to 3 AWS regions from scratch using Terraform and EKS.   Teams can run existing automated demo apps immediately or request a new custom app across all clusters in <15 minutes.
