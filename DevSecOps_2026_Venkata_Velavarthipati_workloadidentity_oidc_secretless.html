    Abstract

    Multi-cloud DevSecOps pipelines frequently move application data, artifacts, and machine learning workloads across provider boundaries, creating security challenges when persistent credentials are embedded in automation. This talk presents a policy-driven approach to secretless multi-cloud authentication using OpenID Connect and workload identity federation to replace long-lived service keys with short-lived, runtime-issued identity assertions. The architecture enables automated data integration between heterogeneous cloud environments while reducing credential exposure and simplifying operational security controls. The session examines how federated workload identities can be incorporated into event-driven pipelines without introducing unnecessary authentication overhead or disrupting high-throughput data movement. It also explores practical design considerations for policy enforcement, identity trust relationships, credential lifecycle management, observability, failure handling, and secure automation across distributed environments. A mathematical model is used to illustrate how reducing credential lifetime changes the persistent-key vulnerability surface as pipeline concurrency increases. The proposed framework removes persistent credential files from cross-cloud workflows and demonstrated more than a 90 percent reduction in persistent credential attack surface while supporting low-latency MLOps data ingestion. Attendees will learn practical patterns for designing secretless CI/CD and data pipelines, applying least-privilege workload identity, and integrating security controls directly into DevSecOps automation without sacrificing scalability, reliability, or developer productivity.
