# Reference Architecture of AI in the Cloud

A talk at [Conf42 Cloud Native 2025](https://www.conf42.com/cloud2025) by [Radu Vunvulea](https://www.conf42.com/speaker_Radu_Vunvulea) (Vice President of Cloud Capabilities @ Endava). Page: https://www.conf42.com/Cloud_Native_2025_Radu_Vunvulea_data_infrastructure_algorithms

## Abstract

Discover the core principles and best practices of deploying AI solutions in the cloud. Learn how to leverage cloud services for efficient, scalable, and robust AI implementations. We dive into reference architecture, covering AI dimensions like pipelines, model training, deployment.
