    Abstract

    Getting an AI agent to work in a demo is easy. Keeping it reliable once real customers are talking to it is a different problem. Real users ask things you never planned for, mix languages and tone, push the agent toward answers it shouldn’t give, and occasionally have conversations that go wrong without anyone noticing. In this talk, I share what we learned taking a customer-facing AI agent from pilot to production. We’ll look at why a single large system prompt breaks down under real traffic, and how moving to a structured approach (intent detection, grounded tool calls, and clear handoff rules to humans) made the agent more predictable. I’ll cover how we used real failures and escalations as our evaluation set, what we log on every conversation so prompt changes can be tied to actual outcomes, and the guardrails we added for topics where a wrong answer has a real cost. Attendees will leave with a practical checklist for designing, testing, and monitoring prompts for any agent that talks directly to customers.
