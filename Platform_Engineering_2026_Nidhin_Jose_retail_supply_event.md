A talk at [Conf42 Platform Engineering 2026](https://www.conf42.com/platform2026) by [Nidhin Jose](https://www.conf42.com/speaker_Nidhin_Jose) (Staff Software Engineer @ Walmart). Page: https://www.conf42.com/Platform_Engineering_2026_Nidhin_Jose_retail_supply_event

## Abstract

Modern retail platforms must continuously respond to changing demand, real-time inventory updates, and distributed order fulfillment while remaining reliable, scalable, and easy to operate. This session explores how Event-Driven Architecture (EDA) provides a strong foundation for platform engineering by enabling resilient, loosely coupled systems that support business-critical retail operations. Using a retail supply chain as the reference architecture, the session examines practical design decisions behind event sourcing, publish-subscribe communication, and Apache Kafka for connecting services responsible for inventory, logistics, and order management. It also discusses how architectural patterns such as Command Query Responsibility Segregation (CQRS) and the Saga pattern help coordinate distributed workflows while maintaining consistency across microservices. Beyond the architecture itself, the presentation focuses on the platform engineering considerations that influence day-to-day operations, including scalability, fault tolerance, asynchronous processing, event ordering, eventual consistency, and service evolution. The session also shares practical lessons from designing event-driven platforms, highlighting common implementation challenges, architectural tradeoffs, and approaches that improve maintainability and operational resilience. Attendees will leave with actionable insights into designing event-driven platforms that simplify service integration, improve system reliability, and support high-volume retail supply chain workloads while maintaining scalability, resilience, and long-term maintainability.
