# Prompt Engineering for AML: Building Reliable Compliance Workflows at Scale

A talk at [Conf42 Prompt Engineering 2026](https://www.conf42.com/prompt2026) by [Pratik Patel](https://www.conf42.com/speaker_Pratik_Patel) (Principal Consultant @ Hexaware Technologies). Page: https://www.conf42.com/Prompt_Engineering_2026_Pratik_Patel_aml_compliance_workflows

Video: https://www.youtube.com/watch?v=mxdV5RpwfrE

## Abstract

Financial crime compliance workflows are increasingly incorporating large language models to summarize transactions, interpret investigation context, generate analyst narratives, and support regulatory reporting. Yet in AML environments, prompt engineering cannot be treated as simple instruction writing. Prompts must operate against governed data, produce traceable outputs, handle incomplete evidence, and avoid introducing unsupported conclusions into compliance decisions. This session presents a practical prompt-engineering framework for building reliable AI-assisted AML and Currency Transaction Reporting workflows on top of cloud-native data platforms.  Drawing on patterns from large-scale financial data modernization, the talk explores how structured prompts, retrieval context, schema-aware instructions, validation layers, and reusable prompt templates can connect curated transactional data with downstream compliance applications. It examines techniques for grounding responses in approved data products, separating factual extraction from interpretive reasoning, controlling output formats, and designing prompts that fail safely when evidence is insufficient. The session also covers testing, observability, prompt versioning, and audit logging for production environments. Attendees will leave with practical design patterns for turning prompt engineering into a governed engineering discipline that improves consistency, reduces manual effort, and supports defensible financial crime operations.
