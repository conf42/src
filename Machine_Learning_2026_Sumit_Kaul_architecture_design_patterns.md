# LLM Agents for Site Reliability: Production-Safe Architectures for AI-Powered Incident Response

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Sumit Kaul](https://www.conf42.com/speaker_Sumit_Kaul) (Staff Software Engineer @ Payjoy). Page: https://www.conf42.com/Machine_Learning_2026_Sumit_Kaul_architecture_design_patterns

Video: https://www.youtube.com/watch?v=0GkcO1pauJc

## Abstract

LLMs can revolutionize incident response—but only with proper guardrails. Discover a production-safe architecture where AI agents accelerate root cause analysis, generate hypotheses, and suggest mitigations while humans keep decision authority. Build trust, not risk.
