# Kubernetes-Native AI Microservices: Scaling Compliant ML Workloads in Regulated Industries

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Manisha Ponugoti](https://www.conf42.com/speaker_Manisha_Ponugoti) (Wright State University). Page: https://www.conf42.com/Kube_Native_2025_Manisha_Ponugoti_microservices_regulated_scalable

Video: https://www.youtube.com/watch?v=q1sb5n1v_PU

## Abstract

Discover how we scaled AI workloads to 10M+ daily requests on Kubernetes while maintaining HIPAA/banking compliance. Learn battle-tested patterns for ML model orchestration, automated compliance validation, and GPU cost optimization that reduced deployment time by 90% and fraud detection by 4x.
