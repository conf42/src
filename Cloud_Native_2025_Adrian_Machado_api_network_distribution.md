# Your API needs to operate on the worldwide edge

A talk at [Conf42 Cloud Native 2025](https://www.conf42.com/cloud2025) by [Adrian Machado](https://www.conf42.com/speaker_Adrian_Machado) (Staff Software Engineer @ Zuplo). Page: https://www.conf42.com/Cloud_Native_2025_Adrian_Machado_api_network_distribution

Video: https://www.youtube.com/watch?v=HBomddyvQps

## Abstract

When you deploy your API on the edge, you’re no more than 50ms from almost all the internet-connected folks in the world. It’s like running a brick-and-mortar business and having a store in 100+ cities worldwide, where you’re globally present but retain the local personalized approach to selling.
