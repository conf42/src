# JavaScript for Social Impact

A talk at [Conf42 JavaScript 2024](https://www.conf42.com/js2024) by [Crystal Yang](https://www.conf42.com/speaker_Crystal_Yang) (Founder & CEO @ Audemy). Page: https://www.conf42.com/JavaScript_2024_Crystal_Yang_16_socialimpact_programming

Video: https://www.youtube.com/watch?v=Dmnz66YWvrA

## Abstract

Are you passionate about using technology to make a difference? Discover how JavaScript can be used for social impact through exploring unique real-world examples showcasing how JavaScript and Web Development driven innovation can lead to tangible social benefits and promote inclusivity.
