# AI-Powered Cloud Security: Lessons from Enterprise CRM Implementations

A talk at [Conf42 Machine Learning 2025](https://www.conf42.com/ml2025) by [Nagasruthi Kattula](https://www.conf42.com/speaker_Nagasruthi_Kattula) (Manager, Software Engineering @ Okta). Page: https://www.conf42.com/Machine_Learning_2025_Nagasruthi_Kattula_security_crm_cloud

## Abstract

Discover how industry giants leverage AI to revolutionize cloud security in CRM systems. Learn from both spectacular successes and devastating failures to implement ML strategies that protect data while driving innovation. Real-world frameworks you can apply tomorrow.
