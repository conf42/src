# Mastering Cloud and Serverless Automation: The SDET’s Guide to Success

A talk at [Conf42 DevOps 2025](https://www.conf42.com/devops2025) by [Saili Maliye](https://www.conf42.com/speaker_Saili_Maliye) (Tools and Automation Engineer). Page: https://www.conf42.com/DevOps_2025_Saili_Maliye_serverless_automation_success

Video: https://www.youtube.com/watch?v=_gxUgFhRtR8

## Abstract

Unlock the future of testing with cloud and serverless automation! This talk equips SDETs with practical strategies to validate APIs, test infrastructure, and tackle performance issues. With Java demos, you’ll learn what works, what to avoid, and how to build scalable, high-quality apps confidently.
