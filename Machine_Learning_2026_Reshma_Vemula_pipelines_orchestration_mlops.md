# Protecting PHI in Machine Learning Development Environments

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Reshma Vemula](https://www.conf42.com/speaker_Reshma_Vemula) (Visualization Developer @ Loma Linda University Health). Page: https://www.conf42.com/Machine_Learning_2026_Reshma_Vemula_pipelines_orchestration_mlops

Video: https://www.youtube.com/watch?v=qennWGFvRtA

## Abstract

Machine learning in healthcare is exploding, but PHI exposure in development environments is driving massive breaches and costs. This talk delivers real data, proven controls, and a practical roadmap to secure ML pipelines without slowing innovation.
