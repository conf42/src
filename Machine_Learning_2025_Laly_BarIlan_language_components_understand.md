# Speaking the Same Language: How Components Let AI (Finally) Understand You

A talk at [Conf42 Machine Learning 2025](https://www.conf42.com/ml2025) by [Laly Bar-Ilan](https://www.conf42.com/speaker_Laly_BarIlan) (Chief Scientist @ Bit). Page: https://www.conf42.com/Machine_Learning_2025_Laly_BarIlan_language_components_understand

Video: https://www.youtube.com/watch?v=qw1pubdZ6i8

## Abstract

This talk shows how composable components act as a shared language between devs, non-tech teams, and AI, enabling systems where AI builds features by understanding product intent, and keeping humans in the loop as systems scale and evolve.
