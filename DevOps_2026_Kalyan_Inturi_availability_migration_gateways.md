# Zero-Downtime by Design: High-Availability Migration Patterns for Modern Gateway & Platform Engineering

A talk at [Conf42 DevOps 2026](https://www.conf42.com/devops2026) by [Kalyan Inturi](https://www.conf42.com/speaker_Kalyan_Inturi) (Principal Member of Technical Staff [Oracle Cloud Infrastructure] @ Oracle Cloud Infrastructure). Page: https://www.conf42.com/DevOps_2026_Kalyan_Inturi_availability_migration_gateways

Video: https://www.youtube.com/watch?v=SPLlxgP1wYQ

## Abstract

A real-world zero-downtime gateway migration powered by shadow traffic, automated pipelines, microservice extraction, and phased rollouts. Learn how to modernize critical systems without breaking production and achieve scalable, resilient platform architecture.
