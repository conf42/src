# The Fifth Golden Signal: Making Accessibility Observable

A talk at [Conf42 Observability 2026](https://www.conf42.com/obs2026) by [Victoria Nduka](https://www.conf42.com/speaker_Victoria_Nduka) (Technical Support Intern @ VictoriaMetrics). Page: https://www.conf42.com/Observability_2026_Victoria_Nduka_accessibility_slos_goldensignals

Video: https://www.youtube.com/watch?v=EjywRDCvSnE

## Abstract

Most engineering teams monitor latency, traffic, errors, and saturation because these metrics directly impact user experience. We build dashboards, configure alerts, and establish SLOs to detect regressions before users notice them. Yet accessibility regressions are often discovered weeks later through audits, bug reports, or frustrated users. Why? Because accessibility is rarely treated as something that can be observed. In this talk, I'll share how I applied cloud-native observability principles to accessibility by transforming automated accessibility scan results into metrics, dashboards, and trend data using open-source tools. Rather than treating accessibility as a periodic compliance exercise, we'll explore how it can become a continuously monitored signal alongside traditional production metrics. If we believe user experience is worth monitoring, then accessibility deserves a place on the dashboard too.
