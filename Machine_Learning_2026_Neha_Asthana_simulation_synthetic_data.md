# IAM and Privileged Access Foundations for Secure Enterprise ML Platforms

A talk at [Conf42 Machine Learning 2026](https://www.conf42.com/ml2026) by [Neha Asthana](https://www.conf42.com/speaker_Neha_Asthana) (Identity Solutions Architect @ Abbott). Page: https://www.conf42.com/Machine_Learning_2026_Neha_Asthana_simulation_synthetic_data

Video: https://www.youtube.com/watch?v=RlyV-J9dAYk

## Abstract

Machine learning platforms are only as secure as the identities behind them. Learn how IAM and Privileged Access Management protect data, models, and pipelines while enabling compliance, visibility, and control across modern enterprise environments.
