# AMMF: Attention-Based Fusion for Cross-Architecture Binary Vulnerability

A talk at [Conf42 Golang 2026](https://www.conf42.com/golang2026) by [Akshaya Jayaram](https://www.conf42.com/speaker_Akshaya_Jayaram) (M&A Security Principal @ Salesforce). Page: https://www.conf42.com/Golang_2026_Akshaya_Jayaram_ammf_attention_based

Video: https://www.youtube.com/watch?v=8AzV_CmQqrs

## Abstract

Binary vulnerability detection remains a critical challenge in modern software security, especially in ecosystems like Go where cross-compilation enables the same codebase to run across diverse architectures. Variations introduced by different compilers, architectures, and optimization settings significantly complicate reliable vulnerability identification at scale.  This work presents AMMF, an attention-driven multi-feature fusion approach for cross-architecture binary vulnerability detection. The method integrates assembly-level semantic information with structural attributes extracted at both basic block and function levels. Instruction semantics are learned through embedding representations, while contextual relationships are modeled using a gated recurrent unit enhanced with self-attention. These semantic representations are fused with control-flow and function-level features via an attention-augmented convolutional architecture to produce unified and discriminative function embeddings.  AMMF adopts a two-stage detection strategy. First, a deep neural similarity model identifies candidate vulnerable functions from large-scale binary corpora. Second, control-flow graph matching refines these candidates to determine final vulnerabilities. This design improves both detection accuracy and efficiency while reducing false positives.  Experimental results show strong accuracy and recall across cross-architecture, cross-compiler, and cross-optimization scenarios. By combining semantic understanding with structural features under attention mechanisms, AMMF improves robustness in real-world settings, making it well-suited for securing software systems built with modern, cross-platform languages like Go.
