# Internal Developer Platform and Kusion: Optimize the software development process

A talk at [Conf42 DevSecOps 2024](https://www.conf42.com/devsecops2024) by [Hoang Dinh Nguyen](https://www.conf42.com/speaker_Hoang_Dinh_Nguyen) (Cloud Engineer @ Viettel Group). Page: https://www.conf42.com/DevSecOps_2024_Hoang_Dinh_Nguyen_developer_platform_kusion

Video: https://www.youtube.com/watch?v=iaOjAkLgXgM

## Abstract

In the fast-paced world of IT, integrating new technologies with cloud computing has improved software development but also increased complexity. What is the fastest way to build an Internal Development Platform and integrate it with all cloud resources to optimize the software development process?
