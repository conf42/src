# Web Workers: Handling Heavy Processing on the Client Side

A talk at [Conf42 DevOps 2024](https://www.conf42.com/devops2024) by [Kevin Uehara](https://www.conf42.com/speaker_Kevin_Uehara) (Staff Front-end Engineer @ iFood). Page: https://www.conf42.com/DevOps_2024_Kevin_Uehara_webworkers_heavy_processing

Video: https://www.youtube.com/watch?v=RXZ46Ury5sw

## Abstract

In this talk, I will provide an overview of how we handle large processes on the client side (WebApp Applications) using a web API called Web Worker. We will create a simple application using vanilla JS, and I will introduce you to this feature
