# Securing and hardening containers hosts

A talk at [Conf42 DevSecOps 2021](https://www.conf42.com/devsecops2021) by [Mathieu Tortuyaux](https://www.conf42.com/speaker_Mathieu_Tortuyaux) (Linux OS Software Engineer @ Microsoft) and [Sayan Chowdhury](https://www.conf42.com/speaker_Sayan_Chowdhury) (Software Engineer @ Microsoft). Page: https://www.conf42.com/DevSecOps_2021_Mathieu_Tortuyaux_Sayan_Chowdhury_securing_hardening_containers_hosts

Video: https://www.youtube.com/watch?v=v-RHlHe8h_8

## Abstract

Even the most secured Kubernetes cluster can have security issues in case the underlying OS is not correctly hardened.

In this talk, we will present the best practices to harden and secure your container hosts from the delivery to the different environments to ensure  reliability, security and performance.

Through an actual live example, we will introduce how Flatcar Container Linux is first built around security, and uses the hardening practices.
From SELinux configuration to audit logs passing by its package management - let's see how this container optimized OS distro  can contribute to reduce the surface attack and mitigate threats.
