# Cloud-Native EV Charging: Scalable, Smart Infrastructure for Electric Mobility

A talk at [Conf42 Kube Native 2025](https://www.conf42.com/kubenative2025) by [Preeti Sali](https://www.conf42.com/speaker_Preeti_Sali) (Senior Technical Program Manager @ Ford Motor Company). Page: https://www.conf42.com/Kube_Native_2025_Preeti_Sali_ev_charging_infrastructure

Video: https://www.youtube.com/watch?v=AiN_W4Av6RA

## Abstract

Discover how cloud-native tech is revolutionizing EV charging! Learn how scalable, intelligent infrastructure powered by Kubernetes and real-time data can cut costs, reduce downtime, and supercharge the path to a sustainable, electrified future.
